Motivation

Why a Statistically Motivated Algorithm?

Finding MLEs usually needs a numerical method (Newton-Raphson, optim). The EM algorithm appears naturally when

  • some parts of the data are missing, and the analysis of the incomplete data is complicated or nonlinear;
  • it is possible to “fill in” the missing data, and the analysis of the complete data is relatively simple.

Examples: missing cells, censored data, mixture models (unknown labels), random effects, hidden Markov models, latent factors.

Filling In: The EM Idea

With no missing data the solution is trivial: \(\hat\mu = \bar y\), \(\hat\alpha_i = \bar y_{i\cdot} - \bar y\), \(\hat\beta_j = \bar y_{\cdot j} - \bar y\).

  1. Fill in \(y_{23}\) (e.g. with the average of the observed data).
  2. Compute the complete-data estimates.
  3. Re-fill: \(\hat y_{23} = \hat\mu + \hat\alpha_2 + \hat\beta_3\). Repeat 2-3 until convergence.
Y <- matrix(c(10, 22, 15, 23, 17, NA), 2); miss <- is.na(Y)
Y[miss] <- mean(Y, na.rm = TRUE)                      # start: 17.4
out <- NULL
for (it in 1:25) {
  mu <- mean(Y); a <- rowMeans(Y) - mu; b <- colMeans(Y) - mu
  out <- rbind(out, c(it, mu, a[1], b[1], b[2]))
  Y[miss] <- mu + a[2] + b[3]
}
colnames(out) <- c("iter", "mu", "alpha1", "beta1", "beta2")

General Specification

Incomplete and Complete Data

  • Observed (incomplete) data \(y\); complete data \(x\) with \(y = h(x)\): \(y\) is determined by \(x\), not vice versa (e.g. \(x = (x_1,x_2,x_3)\), \(y = (x_1, x_2 + 2x_3)\)).
  • We want the MLE from \(L(\theta; y) = p_\theta(y)\), but \(L(\theta; x) = p_\theta(x)\) is easier.

Start with \(\theta^0\). Repeat until convergence:

  • E-step: compute \(Q(\theta) = Q(\theta\mid\theta^0) \equiv \mathrm{E}\{\log L(\theta; x)\mid y, \theta^0\}\).
  • M-step: maximize \(Q(\theta)\) to obtain \(\theta^1\); set \(\theta^0\leftarrow\theta^1\).

\(\log L(\theta;y)\) is approximated by \(Q(\theta\mid\theta^0)\); we maximize the approximation, then re-approximate.

Example 12.2: A Genetic Linkage Model (Rao, 1973)

Phenotype counts \(y = (125, 18, 20, 34)\) are multinomial with probabilities \(\left(\frac12 + \frac\theta4,\ \frac{1-\theta}4,\ \frac{1-\theta}4,\ \frac\theta4\right)\):

\[ \log L(\theta; y) = y_1\log(2+\theta) + (y_2 + y_3)\log(1-\theta) + y_4\log\theta. \]

No closed form. Complete data: split \(y_1 = x_1 + x_2\) with probabilities \(\frac12\) and \(\frac\theta4\); then

\[ \log L(\theta; x) = (x_2 + x_5)\log\theta + (x_3+x_4)\log(1-\theta)\ \Rightarrow\ \hat\theta = \frac{x_2+x_5}{x_2+x_3+x_4+x_5}. \]

E-Step and M-Step for the Linkage Model

  • E-step: \(x_2\mid y_1\sim\text{Bin}\left(y_1,\ \dfrac{\theta^0/4}{1/2 + \theta^0/4}\right)\), so \(\hat x_2 = y_1\dfrac{\theta^0/4}{1/2+\theta^0/4}\).
  • M-step: \(\theta^1 = \dfrac{\hat x_2 + x_5}{\hat x_2 + x_3 + x_4 + x_5}\).
y <- c(125, 18, 20, 34)
theta <- 4 * 34 / 197                                # start from the last category
for (k in 1:6) {
  x2 <- y[1] * (theta / 4) / (1 / 2 + theta / 4)       # E-step
  theta <- (x2 + y[4]) / (x2 + y[2] + y[3] + y[4])     # M-step
  cat(sprintf("iteration %d: theta = %.6f\n", k, theta))
}

  x2 <- y[1] * (t0 / 4) / (1 / 2 + t0 / 4)

Exponential Family and Convergence

Complete Data in the Exponential Family

If \(\log L(\theta;x) = \theta^\text{T}T - A(\theta)\) with sufficient statistic \(T = T(x)\):

  • E-step: \(Q(\theta\mid\theta^n) = \theta^\text{T}\mathrm{E}(T\mid y,\theta^n) - A(\theta)\): only need \(\hat T = \mathrm{E}\{T\mid y,\theta^n\}\).
  • M-step: solve \(\frac{\partial}{\partial\theta}A(\theta) = \hat T\). Since \(A'(\theta) = \mathrm{E}(T\mid\theta)\), the update satisfies

\[ \mathrm{E}(T\mid\theta^{n+1}) = \mathrm{E}(T\mid y,\theta^n), \qquad \text{and at convergence}\qquad \mathrm{E}(T\mid\hat\theta) = \mathrm{E}(T\mid y,\hat\theta). \]

The Missing Information Principle

Taking conditional expectations of \(\log L(\theta;x\mid y) = \log L(\theta;x) - \log L(\theta;y)\):

\[ \mathcal I(\theta; y) = \mathcal I(\theta; x) - \mathcal I(\theta; x\mid y). \]

The information in the incomplete data equals the information in the complete data minus the extra information in \(x\) that is not in \(y\).

Near the solution,

\[ \frac{\theta^{n+1} - \hat\theta}{\theta^n - \hat\theta}\approx\frac{\mathcal I(\hat\theta; x\mid y)}{\mathcal I(\hat\theta; x)}. \]

  • Less missing information \(\Rightarrow\) faster (linear) convergence.
th <- 0.5; it <- numeric(8)
for (k in 1:8) { x2 <- y[1] * (th / 4) / (1 / 2 + th / 4); th <- (x2 + y[4]) / (x2 + y[2] + y[3] + y[4]); it[k] <- th }
that <- it[8]; round(diff(it - that)[1:5] / (it - that)[1:5] + 1, 4)   # ratio of successive errors

General Properties

EM Always Climbs the Likelihood

\[ L(\theta^{n+1}; y)\ge L(\theta^n; y). \qquad (10) \]

Proof sketch. Let \(h(\theta\mid\theta^0) = \mathrm{E}\{\log L(\theta; x\mid y)\mid y,\theta^0\}\), so \(Q(\theta\mid\theta^0) = h(\theta\mid\theta^0) + \log L(\theta; y)\). By the information inequality (\(\mathrm{E}_g\log f\le\mathrm{E}_g\log g\)), \(h(\theta\mid\theta^0)\le h(\theta^0\mid\theta^0)\). Hence

\[ \log L(\theta^1;y) - \log L(\theta^0;y) \ge Q(\theta^1\mid\theta^0) - Q(\theta^0\mid\theta^0)\ge 0. \]

  • Any \(\theta^1\) with \(Q(\theta^1\mid\theta^0)\ge Q(\theta^0\mid\theta^0)\) works (generalized EM).

Pros and Cons

Advantages

  • Numerically stable: monotone climbing (Newton-Raphson lacks this)
  • Handles parameter constraints automatically (each M-step is an MLE)
  • Often simple closed-form steps

Disadvantages

  • Convergence can be very slow (much missing information)
  • No immediate standard errors (use \(\mathcal I(\hat\theta;y)\) numerically, Louis’ method, or the bootstrap)
  • Can be trapped at local maxima or saddle points: use several starting values

Mixture Models

Finite Mixtures

\[ p_\theta(u) = \sum_{j=1}^J\pi_jp_j(u\mid\theta_j),\qquad \log L(\theta; y) = \sum_i\log\Big\{\sum_{j=1}^J\pi_jp_j(y_i\mid\theta_j)\Big\}. \]

  • Constraints \(\sum\pi_j = 1\), \(\pi_j\ge0\), \(\sigma_j > 0\) make naive Newton-Raphson prone to failure.
  • Complete data: \(x_i = (y_i, z_i)\) where \(z_i\) is the (unobserved) component label:

\[ \log L(\theta; x_i) = \sum_{j=1}^J\big\{I(z_i = j)\log p_j(y_i\mid\theta_j) + I(z_i = j)\log\pi_j\big\}. \]

E-Step and M-Step for a Normal Mixture

E-step (posterior membership probabilities, “responsibilities”):

\[ \hat p_{ij} = P(Z_i = j\mid y_i,\theta^0) = \frac{\pi_j^0p_j(y_i\mid\theta_j^0)}{\sum_k\pi_k^0p_k(y_i\mid\theta_k^0)}. \]

M-step (weighted MLEs):

\[ \pi_j = \frac1n\sum_i\hat p_{ij},\qquad \mu_j = \frac{\sum_i\hat p_{ij}y_i}{\sum_i\hat p_{ij}},\qquad \sigma_j^2 = \frac{\sum_i\hat p_{ij}(y_i-\mu_j)^2}{\sum_i\hat p_{ij}}. \]

Example 12.3: Old Faithful Waiting Times (\(N = 299\))

em_normmix <- function(y, pi1, mu, sigma, tol = 1e-8, maxit = 1000) {
  path <- NULL; ll_old <- -Inf
  for (it in 1:maxit) {
    d1 <- pi1 * dnorm(y, mu[1], sigma[1]); d2 <- (1 - pi1) * dnorm(y, mu[2], sigma[2])
    p <- d1 / (d1 + d2)                                                       # E-step
    pi1 <- mean(p)                                                            # M-step
    mu <- c(sum(p * y) / sum(p), sum((1 - p) * y) / sum(1 - p))
    sigma <- sqrt(c(sum(p * (y - mu[1])^2) / sum(p), sum((1 - p) * (y - mu[2])^2) / sum(1 - p)))
    ll <- sum(log(d1 + d2)); path <- rbind(path, c(it, pi1, mu[1], sigma[1], mu[2], sigma[2], ll))
    if (abs(ll - ll_old) < tol) break
    ll_old <- ll
  }
  colnames(path) <- c("iter", "pi1", "mu1", "sigma1", "mu2", "sigma2", "loglik"); path
}

Rizzo Example 14.5: EM for the Quadratic-Form Mixture

Revisit Example 14.4: \(Y\) is an equal mixture of Gamma\((\tfrac12, \tfrac{1}{2\lambda_j})\), \(j = 1,2,3\). The M-step for \(\lambda_j\) (a gamma scale) is a weighted mean: \(\lambda_j = \sum_i\hat p_{ij}y_i\big/\sum_i\hat p_{ij}\).

set.seed(9); m <- 2000
lambda <- c(.6, .25, .15)
lam <- sample(lambda, size = 2000, replace = TRUE)
y <- rgamma(m, shape = .5, rate = 1 / (2 * lam))
N <- 10000; L <- c(.5, .4, .1); tol <- .Machine$double.eps^0.5; L.old <- L + 1
for (j in 1:N) {
  f1 <- dgamma(y, shape = 1/2, rate = 1 / (2 * L[1]))
  f2 <- dgamma(y, shape = 1/2, rate = 1 / (2 * L[2]))
  f3 <- dgamma(y, shape = 1/2, rate = 1 / (2 * L[3]))
  py <- f1 / (f1 + f2 + f3); qy <- f2 / (f1 + f2 + f3); ry <- f3 / (f1 + f2 + f3)   # E-step
  mu1 <- sum(y * py) / sum(py); mu2 <- sum(y * qy) / sum(qy); mu3 <- sum(y * ry) / sum(ry)   # M-step
  L <- c(mu1, mu2, mu3); L <- L / sum(L)
  if (sum(abs(L - L.old) / L.old) < tol) break
  L.old <- L
}

Choosing the Number of Components

em_k <- function(y, K, maxit = 2000) {
  q <- quantile(y, seq(0, 1, length = K + 1)); pr <- rep(1 / K, K)
  mu <- sapply(1:K, function(j) mean(y[y >= q[j] & y <= q[j + 1]])); s <- rep(sd(y) / K, K)
  for (it in 1:maxit) {
    d <- sapply(1:K, function(j) pr[j] * dnorm(y, mu[j], s[j])); p <- d / rowSums(d)
    pr <- colMeans(p); mu <- colSums(p * y) / colSums(p)
    s <- sqrt(colSums(p * outer(y, mu, "-")^2) / colSums(p)); s <- pmax(s, 1)          # floor: waiting times are integers
  }
  ll <- sum(log(rowSums(sapply(1:K, function(j) pr[j] * dnorm(y, mu[j], s[j])))))
  c(K = K, loglik = ll, BIC = -2 * ll + (3 * K - 1) * log(length(y)))
}

Robust Estimation

EM for \(t\) Regression = Iteratively Reweighted Least Squares

\(y_i = x_i^\text{T}\beta + e_i\) with \(e_i\sim\) scaled \(t_k\). Write \(e_i = \sigma z_i/\sqrt{w_i}\), \(z_i\sim N(0,1)\), \(w_i\sim\chi^2_k/k\). With complete data \((y_i, w_i)\) the problem is weighted normal regression.

  • E-step: \(w_i\mid y_i\sim\chi^2_{k+1}/(k + d_i^2)\) with \(d_i^2 = (y_i - \mu_i^0)^2/\sigma^{2(0)}\), so \(\hat w_i = \dfrac{k+1}{k + d_i^2}\).
  • M-step: \(\beta^1 = (\mathbf{X}^\text{T}\mathbf{W}\mathbf{X})^{-1}\mathbf{X}^\text{T}\mathbf{W}\mathbf{y}\), \(\ \sigma^{2(1)} = \frac1n\sum\hat w_i(y_i - x_i^\text{T}\beta^1)^2\).

Outlying observations get small weights: the source of robustness. (\(k\) is chosen by profile likelihood.)

Robust Regression in Action

em_t_reg <- function(X, y, k = 4, maxit = 200, tol = 1e-10) {
  beta <- qr.coef(qr(X), y); s2 <- mean((y - X %*% beta)^2)
  for (it in 1:maxit) {
    d2 <- as.vector((y - X %*% beta)^2 / s2)
    w <- (k + 1) / (k + d2)                                  # E-step
    beta_new <- solve(crossprod(X, w * X), crossprod(X, w * y))   # M-step (weighted LS)
    s2 <- mean(w * (y - X %*% beta_new)^2)
    if (max(abs(beta_new - beta)) < tol) break
    beta <- beta_new
  }
  list(beta = as.vector(beta_new), w = w, iter = it)
}

Summary

  • EM: E-step = expected complete-data log-likelihood; M-step = maximize it.
  • Exponential-family complete data: E-step only needs \(\mathrm{E}(T\mid y,\theta^n)\).
  • Likelihood increases at every iteration; convergence rate = fraction of missing information.
  • Mixtures: responsibilities \(\hat p_{ij}\) and weighted MLEs; choose \(J\) by BIC; use several starts.
  • Robust \(t\) regression: EM = iteratively reweighted least squares.
