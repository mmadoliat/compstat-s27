Why the Bootstrap?

  • In Chapter 7 we simulated from a known model to study a procedure.
  • In practice, \(F\) is unknown. The bootstrap (Efron, 1979) replaces \(F\) with the empirical distribution \(F_n\) and resamples the data.
  • “Pulling oneself up by one’s bootstraps”: estimating sampling variability from a single sample, without formulas and without replicate data sets.

Real world

\(F\ \longrightarrow\ x = (x_1,\dots,x_n)\ \longrightarrow\ \hat\theta = s(x)\)

Bootstrap world

\(F_n\ \longrightarrow\ x^* = (x_1^*,\dots,x_n^*)\ \longrightarrow\ \hat\theta^* = s(x^*)\)

Example 8.1: \(F_n\) and Bootstrap Samples

\(x = \{2,2,1,1,5,4,4,3,1,2\}\): resampling selects 1, 2, 3, 4, 5 with probabilities 0.3, 0.3, 0.1, 0.2, 0.1, i.e., the cdf of a bootstrap observation is \(F_n\).

How many distinct bootstrap samples of size \(n\) are there? (Answer: \(\binom{2n-1}{n}\); for \(n = 15\) that is 77,558,760.)

Bootstrap Estimate of Standard Error

  1. For \(b = 1,\dots,B\): draw \(x^{*(b)}\) by sampling with replacement from \(x\); compute \(\hat\theta^{(b)} = s(x^{*(b)})\).
  2. \(\widehat{\mathrm{se}}_B(\hat\theta^*) = \sqrt{\dfrac1{B-1}\sum_{b=1}^B\big(\hat\theta^{(b)} - \bar{\hat\theta}^*\big)^2}\).
  • \(B = 50\) to \(200\) is usually enough for an SE; confidence intervals need \(B\ge 1000\).

Bootstrap Estimate of Bias

\[ \mathrm{bias}(\hat\theta) = \mathrm{E}[\hat\theta] - \theta,\qquad \widehat{\mathrm{bias}}_B(\hat\theta) = \bar{\hat\theta}^* - \hat\theta. \]

Example 8.4 (law data):

theta.hat <- cor(law$LSAT, law$GPA)
c(bias = mean(obj$t) - theta.hat, se = sd(obj$t))
     bias        se 
-0.007608  0.133722
  • Rule of thumb: if \(|\widehat\mathrm{bias}|/\widehat{\mathrm{se}} < 0.25\), bias correction is usually not worth it (it increases variance).

Example 8.5: Bias of a Ratio Estimate (Patch Data)

Eight subjects wore a placebo, an old, and a new hormone patch. Bioequivalence holds if \(|\theta|\le 0.20\), where

\[ \theta = \frac{\mathrm{E}(\text{new}) - \mathrm{E}(\text{old})}{\mathrm{E}(\text{old}) - \mathrm{E}(\text{placebo})},\qquad \hat\theta = \bar y/\bar z. \]

n <- nrow(patch); B <- 2000; theta.b <- numeric(B)
theta.hat <- mean(patch$y) / mean(patch$z)
set.seed(4750)
for (b in 1:B) {
  i <- sample(1:n, size = n, replace = TRUE)

}

Bootstrap Confidence Intervals

Four Simple Intervals

With replicates \(\hat\theta^{(1)},\dots,\hat\theta^{(B)}\) and quantiles \(\hat\theta^*_{q}\):

  • Standard normal: \(\hat\theta\pm z_{1-\alpha/2}\,\widehat{\mathrm{se}}(\hat\theta)\) (assumes \(\hat\theta\) approximately normal, unbiased)
  • Basic: \(\big(2\hat\theta - \hat\theta^*_{1-\alpha/2},\ 2\hat\theta - \hat\theta^*_{\alpha/2}\big)\) (pivot \(\hat\theta - \theta\))
  • Percentile: \(\big(\hat\theta^*_{\alpha/2},\ \hat\theta^*_{1-\alpha/2}\big)\) (transformation respecting)
  • Bootstrap \(t\): \(\big(\hat\theta - t^*_{1-\alpha/2}\widehat{\mathrm{se}}(\hat\theta),\ \hat\theta - t^*_{\alpha/2}\widehat{\mathrm{se}}(\hat\theta)\big)\), with \(t^{(b)} = (\hat\theta^{(b)} - \hat\theta)/\widehat{\mathrm{se}}(\hat\theta^{(b)})\)

Why the Basic Interval Has That Form

If the distribution of \(\hat\theta - \theta\) is approximated by that of \(\hat\theta^* - \hat\theta\):

\[ 1-\alpha \approx P\big(\hat\theta^*_{\alpha/2} - \hat\theta \le \hat\theta - \theta \le \hat\theta^*_{1-\alpha/2} - \hat\theta\big) = P\big(2\hat\theta - \hat\theta^*_{1-\alpha/2}\le\theta\le 2\hat\theta - \hat\theta^*_{\alpha/2}\big). \]

alpha <- 0.05; th <- obj$t0; q <- quantile(obj$t, c(alpha / 2, 1 - alpha / 2), type = 1)
rbind(normal = th + c(-1, 1) * qnorm(1 - alpha / 2) * sd(obj$t),
      basic = 2 * th - rev(q), percentile = q)
            97.5%   2.5%
normal     0.5143 1.0385
basic      0.5937 1.0948
percentile 0.4580 0.9591

Example 8.11: The Bootstrap \(t\) Interval

Each replicate needs its own SE: a bootstrap inside the bootstrap.

boot.t.ci <- function(x, B = 500, R = 100, level = .95, statistic) {
  x <- as.matrix(x); n <- nrow(x)
  stat <- numeric(B); se <- numeric(B)
  boot.se <- function(x, R, f) {               # local function to compute the bootstrap SE
    x <- as.matrix(x); m <- nrow(x)
    th <- replicate(R, expr = { i <- sample(1:m, size = m, replace = TRUE); f(x[i, ]) })
    return(sd(th))
  }
  for (b in 1:B) {
    j <- sample(1:n, size = n, replace = TRUE)
    y <- x[j, ]
    stat[b] <- statistic(y)
    se[b] <- boot.se(y, R = R, f = statistic)
  }
  stat0 <- statistic(x)
  t.stats <- (stat - stat0) / se
  se0 <- sd(stat)
  alpha <- 1 - level
  Qt <- quantile(t.stats, c(alpha / 2, 1 - alpha / 2), type = 1)
  names(Qt) <- rev(names(Qt))
  rev(stat0 - Qt * se0)
}

Better Intervals: BCa

Bias-corrected and accelerated percentile interval: use adjusted percentiles \(\hat\theta^*_{\alpha_1}, \hat\theta^*_{\alpha_2}\),

\[ \alpha_1 = \Phi\!\left(\hat z_0 + \frac{\hat z_0 + z_{\alpha/2}}{1 - \hat a(\hat z_0 + z_{\alpha/2})}\right),\quad \alpha_2 = \Phi\!\left(\hat z_0 + \frac{\hat z_0 + z_{1-\alpha/2}}{1 - \hat a(\hat z_0 + z_{1-\alpha/2})}\right), \]

  • Bias correction \(\hat z_0 = \Phi^{-1}\!\left(\frac1B\sum_b I(\hat\theta^{(b)} < \hat\theta)\right)\) (median bias of \(\hat\theta^*\))
  • Acceleration (from the jackknife, next lecture) \(\hat a = \dfrac{\sum_i(\bar\theta_{(\cdot)} - \theta_{(i)})^3}{6\big[\sum_i(\bar\theta_{(\cdot)} - \theta_{(i)})^2\big]^{3/2}}\)

BCa is transformation respecting and second-order accurate. If \(\hat z_0 = \hat a = 0\) it reduces to the percentile interval.

Examples 8.13 - 8.15: Computing BCa

boot.BCa <- function(x, th0, th, stat, conf = .95) {
  x <- as.matrix(x); n <- nrow(x); N <- 1:n
  alpha <- (1 + c(-conf, conf)) / 2; zalpha <- qnorm(alpha)
  z0 <- qnorm(sum(th < th0) / length(th))                       # bias correction
  th.jack <- numeric(n)                                         # acceleration via the jackknife
  for (i in 1:n) th.jack[i] <- stat(x, N[-i])
  L <- mean(th.jack) - th.jack
  a <- sum(L^3) / (6 * sum(L^2)^1.5)
  adj.alpha <- pnorm(z0 + (z0 + zalpha) / (1 - a * (z0 + zalpha)))
  limits <- quantile(th, adj.alpha, type = 6)
  list("est" = th0, "BCa" = limits)
}
stat <- function(dat, index) mean(dat[index, 1]) / mean(dat[index, 2])

Example 8.16: Model Selection (Iron Data)

53 measurements of iron content by a chemical and a magnetic method (ironslag in DAAG). Four candidate models:

  1. Linear: \(Y = \beta_0+\beta_1X+\varepsilon\)
  2. Quadratic: \(Y = \beta_0+\beta_1X+\beta_2X^2+\varepsilon\)
  3. Exponential: \(\log Y = \log\beta_0 + \beta_1X + \varepsilon\)
  4. Log-log: \(\log Y = \beta_0 + \beta_1\log X + \varepsilon\)
iron <- as.data.frame(matrix(scan("data/iron.dat", quiet = TRUE), ncol = 2, byrow = TRUE))
names(iron) <- c("chemical", "magnetic")
chemical <- iron$chemical; magnetic <- iron$magnetic
a <- seq(10, 40, .1)
par(mfrow = c(1, 4), mar = c(4, 4, 2, 1))
L1 <- lm(magnetic ~ chemical); plot(chemical, magnetic, main = "Linear", pch = 16); lines(a, L1$coef[1] + L1$coef[2] * a, lwd = 2)
L2 <- lm(magnetic ~ chemical + I(chemical^2)); plot(chemical, magnetic, main = "Quadratic", pch = 16)
lines(a, L2$coef[1] + L2$coef[2] * a + L2$coef[3] * a^2, lwd = 2)
L3 <- lm(log(magnetic) ~ chemical); plot(chemical, magnetic, main = "Exponential", pch = 16)
lines(a, exp(L3$coef[1] + L3$coef[2] * a), lwd = 2)
L4 <- lm(log(magnetic) ~ log(chemical)); plot(log(chemical), log(magnetic), main = "Log-Log", pch = 16)
lines(log(a), L4$coef[1] + L4$coef[2] * log(a), lwd = 2)

Example 8.17: Leave-One-Out Cross-Validation

n <- length(magnetic); e1 <- e2 <- e3 <- e4 <- numeric(n)
for (k in 1:n) {                             # fit models on leave-one-out samples
  y <- magnetic[-k]; x <- chemical[-k]
  J1 <- lm(y ~ x);                   yhat1 <- J1$coef[1] + J1$coef[2] * chemical[k]
  e1[k] <- magnetic[k] - yhat1
  J2 <- lm(y ~ x + I(x^2));          yhat2 <- J2$coef[1] + J2$coef[2] * chemical[k] + J2$coef[3] * chemical[k]^2
  e2[k] <- magnetic[k] - yhat2
  J3 <- lm(log(y) ~ x);              yhat3 <- exp(J3$coef[1] + J3$coef[2] * chemical[k])
  e3[k] <- magnetic[k] - yhat3
  J4 <- lm(log(y) ~ log(x));         yhat4 <- exp(J4$coef[1] + J4$coef[2] * log(chemical[k]))
  e4[k] <- magnetic[k] - yhat4
}
c(linear = mean(e1^2), quadratic = mean(e2^2), exponential = mean(e3^2), loglog = mean(e4^2))
     linear   quadratic exponential      loglog 
      19.56       17.85       18.44       20.45

The quadratic model has the smallest estimated prediction error. For linear smoothers, LOOCV has a shortcut: \(\frac1n\sum\big(e_i/(1-h_{ii})\big)^2\) with leverages \(h_{ii}\) (try mean((resid(L2) / (1 - hatvalues(L2)))^2)).

When Does the Bootstrap Fail?

set.seed(4750); x <- runif(50, 0, 1)                    # theta = 1, theta.hat = max(x)
bmax <- replicate(2000, max(sample(x, replace = TRUE)))
c(P_star_equals_max = mean(bmax == max(x)), theory = 1 - (1 - 1 / 50)^50)
P_star_equals_max            theory 
           0.6200            0.6358 
hist(bmax, breaks = 40, col = "#FFCC00", main = "Bootstrap of the sample maximum: a spike at max(x)")
  • The bootstrap needs \(\hat\theta\) to be a smooth functional of \(F_n\); extremes, boundary parameters, and heavy tails break it.

Summary

  • Bootstrap = plug in \(F_n\) for \(F\), resample with replacement, recompute.
  • SE: \(B\approx 200\); bias: \(\bar{\hat\theta}^* - \hat\theta\); intervals: \(B\ge 1000\)-\(2000\).
  • Normal, basic, percentile, bootstrap \(t\), BCa: prefer BCa (or bootstrap \(t\)) for skewed statistics.
  • boot() + boot.ci() do it all; write the statistic as function(data, i).
  • Cross-validation estimates prediction error for model selection.
