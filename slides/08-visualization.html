  • Rizzo Chapter 5. The theme: we can only see 2 dimensions on a screen, so every method here is a projection, a slicing, or an encoding of p > 2 dimensions.

The Problem

  • Data \(\mathbf{X}\) is \(n\times p\); we see 2 (maybe 3) dimensions at a time.
  • Strategies:
    • Many low-dimensional views: scatterplot matrices, panels (conditioning)
    • Encode variables: color, shape, size, curves (Andrews), lines (parallel coordinates), glyphs (segments, stars)
    • Functions of two variables: surfaces and contours (densities!)
    • Projections: principal components

Example 5.10: Andrews Curves

Each observation \(\mathbf{x}_i = (x_{i1},\dots,x_{ip})\) becomes a curve on \([-\pi,\pi]\):

\[ f_i(t) = \frac{x_{i1}}{\sqrt2} + x_{i2}\sin t + x_{i3}\cos t + x_{i4}\sin 2t + x_{i5}\cos 2t + \cdots \]

andrews <- function(v, t) {
  basis <- cbind(1 / sqrt(2), sapply(seq_len(length(v) - 1), function(j) {
    k <- ceiling(j / 2); if (j %% 2 == 1) sin(k * t) else cos(k * t) }))
  basis %*% v
}
Xs <- scale(iris[, 1:4]); tt <- seq(-pi, pi, length = 200)
curves <- apply(Xs, 1, andrews, t = tt)
matplot(tt, curves, type = "l", lty = 1, col = adjustcolor(c("#C0392B", "#2E5BBA", "#27AE60")[iris$Species], .35),
        xlab = "t", ylab = "f(t)", main = "Andrews curves: iris (scaled)")
legend("topright", levels(iris$Species), col = c("#C0392B", "#2E5BBA", "#27AE60"), lwd = 3, bty = "n")
  • Andrews curves preserve Euclidean distances (up to a constant) because the basis is orthogonal on [-pi, pi]. Close points give close curves.

Principal Components Analysis

PCA: Projections That Keep the Most Variance

  • Find orthogonal directions \(\mathbf{v}_1,\mathbf{v}_2,\dots\) maximizing \(\mathrm{Var}(\mathbf{X}\mathbf{v})\) subject to \(\|\mathbf{v}\| = 1\).
  • Solution: eigenvectors of the sample covariance (or correlation) matrix \(\mathbf{S}= \mathbf{V}\boldsymbol \Lambda\mathbf{V}^\text{T}\).
  • Equivalently, SVD of the centered data \(\tilde\mathbf{X}= \mathbf{U}\mathbf{D}\mathbf{V}^\text{T}\): scores \(\mathbf{U}\mathbf{D}\), loadings \(\mathbf{V}\), variances \(d_j^2/(n-1)\).
Xc <- scale(USArrests)                         # use the correlation matrix
e <- eigen(cor(USArrests)); s <- svd(Xc)
rbind(eigen = e$values, svd = s$d^2 / (nrow(Xc) - 1))
      [,1]   [,2]   [,3]   [,4]
eigen 2.48 0.9898 0.3566 0.1734
svd   2.48 0.9898 0.3566 0.1734
pc <- prcomp(USArrests, scale. = TRUE)
summary(pc)

Proportion of Variance 0.62 0.247 0.0891 0.0434

Other Approaches (Rizzo 5.8)

  • Projection pursuit and grand tours (tourr): look for “interesting” (non-normal) projections
  • Multidimensional scaling (cmdscale): embed a distance matrix in 2-d
  • t-SNE / UMAP: nonlinear embeddings (great for exploration, careful with interpretation)
  • Interactive graphics: plotly, ggiraph, shiny (next week!)
mds <- cmdscale(dist(scale(USArrests)), k = 2)
par(mar = c(4, 4, 1, 1)); plot(mds, type = "n", xlab = "MDS 1", ylab = "MDS 2")
text(mds, labels = state.abb[match(rownames(USArrests), state.name)], cex = .8)

Summary

  • Many small views: pairs, splom, conditioning panels.
  • Correlation structure: reordered correlation heatmaps.
  • Surfaces: persp, wireframe, contour, image, filled.contour, 2-d histograms.
  • Encodings: Andrews curves, parallel coordinates, segment/star glyphs.
  • PCA via eigen / SVD; scree plots and biplots; MDS as a cousin.
