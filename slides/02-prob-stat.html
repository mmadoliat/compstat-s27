Random Variables and Moments (Rizzo 2.1)

  • cdf \(F_X(x) = P(X\le x)\): non-decreasing, right-continuous, \(\lim_{x\to-\infty}F = 0\), \(\lim_{x\to\infty}F=1\)
  • Discrete: pmf \(f_X(x) = P(X=x)\); continuous: pdf \(f_X(x) = F_X'(x)\)
  • \(\mathrm{E}[X] = \int x\, dF(x)\), \(\mathrm{Var}(X) = \mathrm{E}[(X-\mu)^2] = \mathrm{E}[X^2] - \mu^2\)
  • \(\mathrm{Cov}(X,Y) = \mathrm{E}[(X-\mu_X)(Y-\mu_Y)]\), \(\rho(X,Y) = \dfrac{\mathrm{Cov}(X,Y)}{\sigma_X\sigma_Y}\)

Uncorrelated does not imply independent, except when \((X, Y)\) is jointly normal.

  • For iid \(X_1,\dots,X_n\): \(\mathrm{E}[\bar X] = \mu\), \(\mathrm{Var}(\bar X) = \sigma^2/n\).

Conditional Expectation Rule and Conditional Variance Formula

\[ \mathrm{E}[X] = \mathrm{E}\big[\mathrm{E}[X\mid Y]\big] \qquad (2.1) \] \[ \mathrm{Var}(X) = \mathrm{E}\big[\mathrm{Var}(X\mid Y)\big] + \mathrm{Var}\big(\mathrm{E}[X\mid Y]\big) \qquad (2.2) \]

Example (Poisson-Gamma mixture). \(X\mid \Lambda \sim\text{Poisson}(\Lambda)\), \(\Lambda\sim\text{Gamma}(r, \beta)\).

  • (2.1): \(\mathrm{E}[X] = \mathrm{E}[\Lambda] = r/\beta\)
  • (2.2): \(\mathrm{Var}(X) = \mathrm{E}[\Lambda] + \mathrm{Var}(\Lambda) = r/\beta + r/\beta^2\)
set.seed(4750)
r <- 4; beta <- 2; n <- 1e5
lambda <- rgamma(n, shape = r, rate = beta)
x <- rpois(n, lambda)
rbind(simulation = c(mean = mean(x), var = var(x)),
      formulas   = c(r / beta, r / beta + r / beta^2))
            mean   var
simulation 1.997 3.003
formulas   2.000 3.000
  • This mixture is the negative binomial distribution: X ~ NegBin(r, p = beta/(1+beta)). Check with dnbinom.
  • HW 1 asks you to do exactly this for two other hierarchical models.

Some Discrete Distributions (Rizzo 2.2)

  • Binomial \(X\sim\text{Bin}(n,p)\): number of successes in \(n\) Bernoulli trials; \(np\), \(np(1-p)\)
  • Multinomial: counts in \(k\) categories
  • Geometric: \(P(X = x) = p q^x\), \(x=0,1,\dots\) (failures before first success); cdf \(1-q^{x+1}\) (Example 2.1)
  • Negative binomial \((r,p)\): failures before \(r\)th success; \(\binom{x+r-1}{r-1}p^rq^x\) (2.6)
  • Poisson\((\lambda)\): \(e^{-\lambda}\lambda^x/x!\); mean = variance = \(\lambda\) (Example 2.2)
par(mfrow = c(2, 2), mar = c(4, 4, 2, 1))
k <- 0:15
plot(k, dbinom(k, 15, .4), type = "h", lwd = 5, main = "Bin(15, .4)", ylab = "")
plot(k, dgeom(k, .25), type = "h", lwd = 5, main = "Geom(.25)", ylab = "")
plot(k, dnbinom(k, 3, .4), type = "h", lwd = 5, main = "NegBin(3, .4)", ylab = "")
plot(k, dpois(k, 4), type = "h", lwd = 5, main = "Poisson(4)", ylab = "")

Some Continuous Distributions (Rizzo 2.3)

  • Normal \(N(\mu,\sigma^2)\): \(Z = (X-\mu)/\sigma\sim N(0,1)\)
  • Gamma\((r,\lambda)\): \(f(x) = \frac{\lambda^r}{\Gamma(r)} x^{r-1}e^{-\lambda x}\); Exponential = Gamma\((1,\lambda)\); \(\chi^2(\nu)\) = Gamma\((\nu/2, 1/2)\)
  • Beta\((\alpha,\beta)\) on \((0,1)\); Uniform(0,1) = Beta(1,1)
  • Lognormal: \(\log X\sim N(\mu,\sigma^2)\)
  • Student \(t(\nu)\) \(= Z/\sqrt{V/\nu}\), \(F(\nu_1,\nu_2)\) \(= (U/\nu_1)/(V/\nu_2)\)
set.seed(4750); z <- rnorm(1e5); v <- rchisq(1e5, df = 5)
tt <- z / sqrt(v / 5)
rbind(quantile(tt, c(.9, .95, .99)), qt(c(.9, .95, .99), df = 5))

Memoryless Exponential (Examples 2.3 - 2.4)

\[ P(X > s + t \mid X > s) = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X>t). \]

set.seed(2027); x <- rexp(1e6, rate = 0.5); s <- 2; t <- 3
c(conditional = mean(x[x > s] > s + t), unconditional = mean(x > t), exact = exp(-0.5 * t))
  conditional unconditional         exact 
       0.2233        0.2236        0.2231
  • Two-parameter exponential with location \(\eta\): \(F(x) = 1 - e^{-\lambda(x-\eta)}\), \(x\ge\eta\) (shift a standard exponential).

Multivariate Normal (Rizzo 2.4)

\[ f(\mathbf{x}) = \frac{1}{(2\pi)^{d/2}|\boldsymbol \Sigma|^{1/2}}\exp\left\{-\tfrac12(\mathbf{x}-\boldsymbol \mu)^\text{T}\boldsymbol \Sigma^{-1}(\mathbf{x}-\boldsymbol \mu)\right\} \]

  • Marginals and conditionals of a MVN are normal; linear transformations \(\mathbf{A}\mathbf{X}+\mathbf{b}\sim N(\mathbf{A}\boldsymbol \mu+\mathbf{b}, \mathbf{A}\boldsymbol \Sigma\mathbf{A}^\text{T})\)
  • If \(\mathbf{Z}\sim N_d(\mathbf 0, \mathbf{I})\) and \(\boldsymbol \Sigma= \mathbf{C}\mathbf{C}^\text{T}\), then \(\mathbf{X}= \boldsymbol \mu+ \mathbf{C}\mathbf{Z}\sim N_d(\boldsymbol \mu,\boldsymbol \Sigma)\) (Ch 3!)
Sigma <- matrix(c(1, .8, .8, 1), 2); C <- t(chol(Sigma))
set.seed(4750); Z <- matrix(rnorm(2 * 2000), nrow = 2)
X <- t(c(1, 2) + C %*% Z)
round(cov(X), 2)
     [,1] [,2]
[1,] 0.97 0.74
[2,] 0.74 0.92
plot(X, pch = 20, col = adjustcolor("#003366", .4), asp = 1, xlab = "x1", ylab = "x2")

Limit Theorems (Rizzo 2.5)

  • WLLN: \(\bar X_n \xrightarrow{P}\mu\); SLLN: \(\bar X_n \xrightarrow{a.s.}\mu\)
  • CLT: \(\dfrac{\bar X_n-\mu}{\sigma/\sqrt n}\xrightarrow{D} N(0,1)\) when \(\sigma^2<\infty\)

Statistics (Rizzo 2.6): ecdf and Quantiles

  • ecdf \(F_n(x) = \frac1n\#\{i: x_i\le x\}\)
  • \(q\)-quantile: \(X_q = \inf\{x: F(x)\ge q\}\); R’s default quantile(type = 7) assigns \((k-1)/(n-1)\) to \(x_{(k)}\)

Bias, Standard Error, and MSE

  • \(\mathrm{bias}(\hat\theta) = \mathrm{E}[\hat\theta] - \theta\); unbiased if bias \(=0\)
  • \(\mathrm{se}(\hat\theta) = \sqrt{\mathrm{Var}(\hat\theta)}\)
  • \(\mathrm{MSE}(\hat\theta) = \mathrm{E}[(\hat\theta-\theta)^2] = \mathrm{Var}(\hat\theta) + \mathrm{bias}^2(\hat\theta)\)

Example. For \(N(\mu,\sigma^2)\), compare \(S^2\) (divisor \(n-1\)) with \(\hat\sigma^2\) (divisor \(n\)):

set.seed(4750); n <- 10; sigma2 <- 4
sims <- replicate(1e5, { x <- rnorm(n, sd = 2); c(S2 = var(x), mle = var(x) * (n - 1) / n) })
rbind(bias = rowMeans(sims) - sigma2, MSE = rowMeans((sims - sigma2)^2))
            S2     mle
bias -0.006832 -0.4061
MSE   3.547734  3.0386

The biased estimator has the smaller MSE: the bias-variance trade-off we will see again in ridge regression and Bayes estimators.

Maximum Likelihood (Examples 2.5 - 2.6)

  • \(L(\theta) = \prod_{i=1}^n f(x_i\mid\theta)\), \(\hat\theta = \mathop{\mathrm{arg\,max}}_\theta \log L(\theta)\)
  • Example 2.5: for \(N(\mu,\sigma^2)\), \(\hat\mu = \bar x\), \(\hat\sigma^2 = \frac1n\sum(x_i-\bar x)^2\)
  • Invariance (Example 2.6): if \(\hat\theta\) is the MLE of \(\theta\), then \(g(\hat\theta)\) is the MLE of \(g(\theta)\) (e.g. \(\hat\sigma = \sqrt{\hat\sigma^2}\))
set.seed(4750); x <- rnorm(50, mean = 5, sd = 2)
negll <- function(par) -sum(dnorm(x, par[1], exp(par[2]), log = TRUE))
fit <- optim(c(0, 0), negll)
c(mu_hat = fit$par[1], sigma_hat = exp(fit$par[2]),
  closed_form_mu = mean(x), closed_form_sigma = sqrt(mean((x - mean(x))^2)))
           mu_hat         sigma_hat    closed_form_mu closed_form_sigma 
            5.224             2.153             5.224             2.154
  • We parametrize log(sigma) so the optimizer is unconstrained. More on optim in Chapter 14, and on MOM/MLE/Bayes in deck 05.

Bayes’ Theorem and Bayesian Statistics (Rizzo 2.7)

\[ \pi(\theta\mid x) = \frac{f(x\mid\theta)\pi(\theta)}{\int f(x\mid\theta)\pi(\theta)\,d\theta} \;\propto\; \text{likelihood}\times\text{prior} \]

Beta-Binomial: \(X\mid p\sim\text{Bin}(n,p)\), \(p\sim\text{Beta}(a,b)\) \(\Rightarrow\) \(p\mid x\sim\text{Beta}(a+x,\, b+n-x)\).

a <- 2; b <- 2; n <- 20; xobs <- 14
curve(dbeta(x, a, b), 0, 1, lwd = 3, lty = 2, ylim = c(0, 4.5), ylab = "density", xlab = "p")
curve(dbeta(x, a + xobs, b + n - xobs), add = TRUE, lwd = 3, col = "#003366")
abline(v = xobs / n, col = "red", lwd = 2)
legend("topleft", c("prior Beta(2,2)", "posterior Beta(16,8)", "MLE 14/20"), lty = c(2, 1, 1),
       col = c(1, "#003366", "red"), lwd = 3, bty = "n")

Markov Chains (Rizzo 2.8)

  • \(\{X_t\}\) with \(P(X_{t+1}=j\mid X_t = i, X_{t-1},\dots) = p_{ij}\); transition matrix \(\mathbf P = (p_{ij})\), rows sum to 1
  • \(n\)-step transitions: \(\mathbf P^n\); stationary distribution \(\boldsymbol\pi^\text{T}= \boldsymbol\pi^\text{T}\mathbf P\)

Example 2.7 (DNA mutation). \(p_{ii} = 1-3\alpha\), \(p_{ij} = \alpha\), \(\alpha = 0.1\).
