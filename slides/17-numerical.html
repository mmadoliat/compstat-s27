Example: The Sample Variance, Two Ways

\[ S^2 = \frac{1}{n-1}\sum(x_i-\bar x)^2 \quad\text{vs.}\quad S^2 = \frac{\sum x_i^2 - n\bar x^2}{n-1} \]

set.seed(4750); x <- rnorm(1000, mean = 1e9, sd = 1)    # true variance 1
two_pass <- sum((x - mean(x))^2) / (length(x) - 1)
one_pass <- (sum(x^2) - length(x) * mean(x)^2) / (length(x) - 1)
c(var = var(x), two_pass = two_pass, textbook_one_pass = one_pass)
              var          two_pass textbook_one_pass 
           0.9781            0.9781            0.0000

The “computational formula” from intro statistics is numerically unstable. Use two-pass or Welford’s online algorithm (our R6 example in the OOP lecture).

Series for Large Arguments: Order Matters

x <- 20
naive <- sum((-1)^(0:60) * x^(2 * (0:60) + 1) / factorial(2 * (0:60) + 1))
reduced <- { xr <- x %% (2 * pi); sum((-1)^(0:30) * xr^(2 * (0:30) + 1) / factorial(2 * (0:30) + 1)) }
c(naive = naive, range_reduced = reduced, sin = sin(20))
        naive range_reduced           sin 
       0.9129        0.9129        0.9129
  • Terms like \(20^{41}/41!\) are huge and alternate in sign: cancellation destroys accuracy. Reduce the argument first.

Numerical Derivatives (cf. Examples 13.4 - 13.5)

Forward difference \(\frac{f(x+h) - f(x)}{h}\) has truncation error \(O(h)\) and rounding error \(O(\epsilon/h)\): the best \(h\approx\sqrt\epsilon\). Central differences: \(O(h^2)\), best \(h\approx\epsilon^{1/3}\).

f <- function(x) exp(x); x0 <- 1; h <- 10^seq(-16, -1, by = .25)
fwd <- abs((f(x0 + h) - f(x0)) / h - exp(1))
ctr <- abs((f(x0 + h) - f(x0 - h)) / (2 * h) - exp(1))
plot(h, fwd, log = "xy", type = "l", lwd = 3, ylab = "absolute error", main = "Truncation vs rounding error")
lines(h, ctr, lwd = 3, col = "#C0392B"); abline(v = c(sqrt(.Machine$double.eps), .Machine$double.eps^(1/3)), lty = 2)
legend("bottom", c("forward", "central"), col = c(1, "#C0392B"), lwd = 3, bty = "n")

Derivative of the Zeta Function (Example 13.5)

\(\zeta(a) = \sum_{i\ge1}i^{-a}\), \(a > 1\), and \(\zeta'(a) = -\sum_{i\ge1}\frac{\log i}{i^a}\). Summing the series directly converges slowly; the book uses a Laurent expansion with Stieltjes constants. A simple check:

zeta <- function(a, N = 1e6) { i <- 1:N; sum(i^-a) + N^(1 - a) / (a - 1) }   # tail correction
dzeta_series <- function(a, N = 1e6) { i <- 1:N; -sum(log(i) * i^-a) - N^(1 - a) * (log(N) / (a - 1) + 1 / (a - 1)^2) }
a <- 2; h <- 1e-4
c(series = dzeta_series(a), central_difference = (zeta(a + h) - zeta(a - h)) / (2 * h), known = -0.9375482543)
            series central_difference              known 
           -0.9375            -0.9375            -0.9375

Lecture B: Root Finding, Integration, MLE

Root Finding: Bisection

If \(f\) is continuous on \([a,b]\) and \(f(a)f(b) < 0\), a root lies in \((a,b)\). Halve the interval each step: error after \(k\) steps \(\le (b-a)/2^k\) (linear convergence).

Example 13.6. Solve \(a^2 + y^2 + \dfrac{2ay}{n-1} = n-2\) for \(y\), with \(a = 0.5\), \(n = 20\). Exact: \(y = -\dfrac{a}{n-1}\pm\sqrt{n-2-a^2+\left(\dfrac{a}{n-1}\right)^2}\) (the 2nd edition prints \(+a^2\) under the root, a typo).

f <- function(y, a, n) a^2 + y^2 + 2 * a * y / (n - 1) - (n - 2)
a <- 0.5; n <- 20
b0 <- 0; b1 <- 5* n; it <- 0; eps <- .Machine$double.eps^0.25
y <- seq(b0, b1, length = 100)
r <- c(b0, b1); f0 <- f(b0, a, n); f1 <- f(b1, a, n)
while (it < 1000 && abs(r[2] - r[1]) > eps) {
  it <- it + 1; mid <- mean(r); fm <- f(mid, a, n)
  if (fm == 0) { r <- c(mid, mid); break }
  if (f0 * fm < 0) { r[2] <- mid; f1 <- fm } else { r[1] <- mid; f0 <- fm }
}
c(root = mean(r), iterations = it, exact = -a / (n - 1) + sqrt(n - 2 - a^2 + (a / (n - 1))^2))
      root iterations      exact 
     4.187     20.000      4.187

Example 13.7: Brent’s Method with uniroot

Brent’s method combines bisection, the secant method, and inverse quadratic interpolation: guaranteed and fast.

out <- uniroot(function(y) f(y, a, n), lower = 0, upper = 5 * n)
unlist(out[c("root", "f.root", "iter", "estim.prec")])
      root     f.root       iter estim.prec 
 4.187e+00  2.381e-04  1.400e+01  6.104e-05

Newton-Raphson: \(x_{k+1} = x_k - f(x_k)/f'(x_k)\), quadratic convergence near the root but no guarantee.

newton <- function(f, df, x, tol = 1e-12, maxit = 50) {
  for (k in 1:maxit) { step <- f(x) / df(x); x <- x - step; if (abs(step) < tol) break }
  c(root = x, iterations = k)
}
newton(function(y) f(y, a, n), function(y) 2 * y + 2 * a / (n - 1), x = 1)
      root iterations 
     4.187      7.000

Numerical Integration: integrate()

Adaptive Gauss-Kronrod quadrature (QUADPACK). Handles infinite limits by transformation.

Quadrature by Hand: Trapezoid and Simpson

trap <- function(f, a, b, m) { x <- seq(a, b, length = m + 1); h <- (b - a) / m; h * (sum(f(x)) - (f(a) + f(b)) / 2) }
simpson <- function(f, a, b, m) {                    # m even
  x <- seq(a, b, length = m + 1); h <- (b - a) / m
  h / 3 * (f(a) + f(b) + 4 * sum(f(x[seq(2, m, 2)])) + 2 * sum(f(x[seq(3, m - 1, 2)])))
}
g <- function(x) exp(-x) / (1 + x^2); exact <- integrate(g, 0, 1, rel.tol = 1e-12)$value
sapply(c(4, 16, 64), function(m) c(m = m, trapezoid_err = trap(g, 0, 1, m) - exact, simpson_err = simpson(g, 0, 1, m) - exact))
                    [,1]       [,2]       [,3]
m              4.0000000  1.600e+01  6.400e+01
trapezoid_err  0.0033273  2.059e-04  1.286e-05
simpson_err   -0.0001636 -5.374e-07 -2.083e-09

Example 13.9: Density of the Sample Correlation

For bivariate normal data with correlation \(\rho\), the density of \(r\) is

\[ f(r) = \frac{(n-2)(1-\rho^2)^{(n-1)/2}(1-r^2)^{(n-4)/2}}{\pi}\int_0^\infty\frac{dw}{(\cosh w - \rho r)^{n-1}},\quad -1<r<1. \]

.dcorr <- function(r, N, rho = 0) {
  if (abs(r) > 1 || abs(rho) > 1) return(0)
  if (N < 4) return(NA)
  if (isTRUE(all.equal(rho, 0.0))) {
    a <- exp(lgamma((N - 1) / 2) - lgamma((N - 2) / 2))
    return(a * (1 - r^2)^((N - 4) / 2) / sqrt(pi))
  }
  f <- function(w, R, N, rho) (cosh(w) - rho * R)^(1 - N)        # integrand
  i <- integrate(f, lower = 0, upper = Inf, R = r, N = N, rho = rho)$value
  c1 <- (N - 2) * (1 - rho^2)^((N - 1) / 2)
  c2 <- (1 - r^2)^((N - 4) / 2) / pi
  c1 * c2 * i
}
dcorr <- function(r, N, rho = 0) sapply(r, .dcorr, N = N, rho = rho)
integrate(dcorr, -1, 1, N = 10, rho = 0.5)$value                     # a proper density?
[1] 1

Application: Evaluating an Expected Value (Examples 13.11 - 13.13)

\(X\sim\text{Pareto}(\sigma, \alpha = 1)\), \(\bar F(x) = (\sigma/x)^\alpha\), \(x\ge\sigma\). For \(y>\sigma\) and \(0<\beta<1\), evaluate \(\mathrm{E}|y - X|^\beta\) (it arises in energy goodness-of-fit tests).

f1 <- function(x, y, s, a, b) (abs(y - x))^b * a * s^a / x^(a + 1)     # the integrand |y-x|^b f(x)
g1 <- function(y, s, a, b) {                                            # E|y-X|^b by numerical integration
  if (y < s) return(NA)
  integrate(f1, lower = s, upper = y, y = y, s = s, a = a, b = b)$value +
    integrate(f1, lower = y, upper = Inf, y = y, s = s, a = a, b = b)$value
}
sapply(c(1.5, 2, 5, 10), g1, s = 1, a = 1, b = .5)
[1] 1.452 1.487 2.057 2.922
set.seed(4750); X <- 1 / runif(1e6)                                     # Pareto(1, 1) by inverse transform
sapply(c(1.5, 2, 5, 10), function(y) mean(abs(y - X)^.5))               # Monte Carlo check
[1] 1.446 1.481 2.050 2.915
  • The book also derives a closed form as an infinite series (hypergeometric functions, VGAM/gsl) and compares it with integrate; the plot of E|y - X|^b versus y is Example 13.13.

Summary

  • Doubles have about 16 significant digits; avoid == (use isTRUE(all.equal())), avoid subtracting nearly equal numbers, work on the log scale.
  • Derivatives: step size \(\sqrt\epsilon\) (forward) or \(\epsilon^{1/3}\) (central).
  • Roots: bisection (safe), Newton (fast), Brent’s uniroot (both).
  • Integrals: integrate() (vectorize the integrand, beware of peaks), trapezoid/Simpson, Monte Carlo in high dimensions.
  • MLE: optimize() (1-d), stats4::mle(), optim() (next lecture).
