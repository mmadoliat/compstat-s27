Shrinkage Methods: Ridge Regression and Lasso

  • Subset selection fits least squares on a subset of the predictors.
  • Alternative: fit a model with all \(p\) predictors using a technique that constrains or regularizes the coefficients, i.e., shrinks them toward zero.
  • Shrinking the coefficient estimates can significantly reduce their variance.

Recall least squares minimizes \[ \text{RSS} = \sum_{i=1}^n\Big(y_i - \beta_0 - \sum_{j=1}^p\beta_jx_{ij}\Big)^2. \]

Ridge Regression

\[ \hat\boldsymbol \beta^R_\lambda = \mathop{\mathrm{arg\,min}}_{\boldsymbol \beta}\;\sum_{i=1}^n\Big(y_i - \beta_0 - \sum_{j=1}^p\beta_jx_{ij}\Big)^2 + \lambda\sum_{j=1}^p\beta_j^2 = \text{RSS} + \lambda\sum_{j=1}^p\beta_j^2 \]

  • \(\lambda\ge0\) is a tuning parameter; \(\lambda\sum_j\beta_j^2\) is the shrinkage penalty (the intercept is not penalized).
  • \(\lambda = 0\): least squares. \(\lambda\to\infty\): all \(\beta_j\to 0\).
  • Closed form (centered \(\mathbf{y}\), standardized \(\mathbf{X}\)):

\[ \hat\boldsymbol \beta^R_\lambda = (\mathbf{X}^\text{T}\mathbf{X}+ \lambda\mathbf{I})^{-1}\mathbf{X}^\text{T}\mathbf{y} \]

\(\mathbf{X}^\text{T}\mathbf{X}+ \lambda\mathbf{I}\) is invertible for every \(\lambda > 0\), even when \(p > n\) or the predictors are collinear.

Ridge Regression: Scaling of Predictors

  • Least squares estimates are scale equivariant: multiplying \(X_j\) by \(c\) scales \(\hat\beta_j\) by \(1/c\).
  • Ridge estimates can change substantially when a predictor is rescaled, because of the penalty \(\sum_j\beta_j^2\).
  • Therefore, standardize the predictors first:

\[ \tilde x_{ij} = \frac{x_{ij}}{\sqrt{\frac1n\sum_{i=1}^n(x_{ij}-\bar x_j)^2}} \]

X2 <- Xs; X2[, "Income"] <- X2[, "Income"] * 1000            # income in dollars, not $1000s
r1 <- solve(crossprod(Xs) + 50 * diag(11), crossprod(Xs, yc))["Income", ]
r2 <- solve(crossprod(X2) + 50 * diag(11), crossprod(X2, yc))["Income", ] * 1000
c(standardized = r1, rescaled = r2)     # not the same fit!
standardized.Income     rescaled.Income 
             -154.3              -203.0

Why Does Ridge Help? Bias-Variance Trade-off

set.seed(4750); ns <- 50; p <- 45; beta <- rnorm(p, sd = 0.4)
Xsim <- matrix(rnorm(ns * p), ns); Xtest <- matrix(rnorm(500 * p), 500)
ftest <- Xtest %*% beta
lam <- 10^seq(-2, 3, length = 30)
fits <- replicate(100, {
  ysim <- Xsim %*% beta + rnorm(ns)
  sapply(lam, function(l) Xtest %*% solve(crossprod(Xsim) + l * diag(p), crossprod(Xsim, ysim)))
}, simplify = "array")                       # 500 x 30 x 100
bias2 <- colMeans((apply(fits, c(1, 2), mean) - as.vector(ftest))^2)
variance <- colMeans(apply(fits, c(1, 2), var))
matplot(lam, cbind(bias2, variance, bias2 + variance), type = "l", lwd = 3, lty = 1, log = "x",
        col = c("black", "#2E8B57", "#C2185B"), xlab = expression(lambda), ylab = "")
legend("top", c("squared bias", "variance", "MSE"), col = c("black", "#2E8B57", "#C2185B"), lwd = 3, bty = "n")
  • With p = 45 close to n = 50, least squares has huge variance. Ridge trades a little bias for a large reduction in variance.

The Lasso

  • Ridge always includes all \(p\) predictors in the final model; it cannot select variables.
  • The lasso minimizes

\[ \sum_{i=1}^n\Big(y_i - \beta_0 - \sum_{j=1}^p\beta_jx_{ij}\Big)^2 + \lambda\sum_{j=1}^p|\beta_j| = \text{RSS} + \lambda\|\boldsymbol \beta\|_1 \]

  • The \(\ell_1\) penalty forces some coefficients to be exactly zero when \(\lambda\) is large enough \(\Rightarrow\) variable selection, sparse models.
  • As with ridge, choosing \(\lambda\) is critical: cross-validation.

Lasso by Coordinate Descent

Minimizing over one coordinate \(\beta_j\) with the others fixed has a closed-form soft-thresholding solution

\[ \beta_j \leftarrow \frac{S\!\left(\sum_i x_{ij}r_{ij},\ \lambda/2\right)}{\sum_i x_{ij}^2},\qquad S(z,\gamma) = \text{sign}(z)(|z|-\gamma)_+ , \]

where \(r_{ij} = y_i - \sum_{k\neq j}x_{ik}\beta_k\) is the partial residual. Cycle over \(j\) until convergence.

soft <- function(z, g) sign(z) * pmax(abs(z) - g, 0)
lasso_cd <- function(X, y, lambda, beta = rep(0, ncol(X)), tol = 1e-4, maxit = 1e4) {
  r <- as.vector(y - X %*% beta); xx <- colSums(X^2)
  for (it in 1:maxit) {
    old <- beta
    for (j in seq_along(beta)) {
      r <- r + X[, j] * beta[j]                       # partial residual
      beta[j] <- soft(sum(X[, j] * r), lambda / 2) / xx[j]
      r <- r - X[, j] * beta[j]
    }
    if (max(abs(beta - old)) < tol) break
  }
  beta
}

Choosing \(\lambda\) by Cross-Validation

set.seed(4750)
folds <- sample(rep(1:5, length.out = nrow(Xs))); lamCV <- 10^seq(4, 0, length = 20)
cv_err <- rowMeans(sapply(1:5, function(k) {
  tr <- folds != k; mx <- colMeans(Xs[tr, ]); my <- mean(yc[tr])
  Xtr <- sweep(Xs[tr, ], 2, mx); Xte <- sweep(Xs[!tr, ], 2, mx); b <- rep(0, ncol(Xs))
  sapply(lamCV, function(l) {                       # warm starts along the path
    b <<- lasso_cd(Xtr, yc[tr] - my, l, beta = b)
    mean((yc[!tr] - my - Xte %*% b)^2)
  })
}))
plot(lamCV, cv_err, log = "x", type = "b", pch = 19, col = "#003366",
     xlab = expression(lambda), ylab = "5-fold CV error")
abline(v = lamCV[which.min(cv_err)], lty = 2, col = "red")

In practice: cv.glmnet(X, y, alpha = 1) does this (with the “one-standard-error” rule as an option). We study cross-validation in Chapter 8.

The Variable Selection Property of the Lasso

Why does the lasso, unlike ridge, give coefficients that are exactly zero? Equivalent constrained problems:

Lasso: \(\displaystyle\min_{\boldsymbol \beta}\ \text{RSS}\quad\text{s.t.}\ \sum_{j=1}^p|\beta_j|\le s\)

Ridge: \(\displaystyle\min_{\boldsymbol \beta}\ \text{RSS}\quad\text{s.t.}\ \sum_{j=1}^p\beta_j^2\le s\)

The RSS ellipses first touch the \(\ell_1\) diamond at a corner (some \(\beta_j = 0\)); the \(\ell_2\) disk has no corners.

Flexibility of the “Loss + Penalty” Framework

\[ \text{Minimize}\ \ \color{blue}{\text{Loss}} + \lambda\,\color{red}{\text{Penalty}} \]

Loss Penalty Algorithm
Hinge: \(\sum_i[1-y_if(\mathbf x_i)]_+\) \(\lambda\&#124;\mathbf w\&#124;_2^2\) SVM
Squared error: \(\sum_i(y_i - f(\mathbf x_i))^2\) \(\lambda\&#124;\mathbf w\&#124;_2^2\) Ridge regression
Squared error \(\lambda\&#124;\mathbf w\&#124;_1\) Lasso
Squared error \(\lambda_1\&#124;\mathbf w\&#124;_1 + \lambda_2\&#124;\mathbf w\&#124;_2^2\) Elastic net
Hinge \(\lambda\&#124;\mathbf w\&#124;_1\) 1-norm SVM
Negative log-likelihood \(\lambda\&#124;\mathbf w\&#124;_1\) Penalized logistic regression

Summary

  • Ridge: \(\ell_2\) penalty, closed form \((\mathbf{X}^\text{T}\mathbf{X}+\lambda\mathbf{I})^{-1}\mathbf{X}^\text{T}\mathbf{y}\), shrinks but keeps all predictors.
  • Lasso: \(\ell_1\) penalty, soft-thresholding by coordinate descent, produces sparse models.
  • Standardize predictors before penalizing.
  • Tune \(\lambda\) by cross-validation; penalization trades bias for variance.
