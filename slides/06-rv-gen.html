Lecture A: Inverse Transform and Acceptance-Rejection

Why Generate Random Variables?

  • Every simulation in this course (Monte Carlo integration, power studies, bootstrap, MCMC) needs random variates from a specified distribution.
  • R already has rnorm, rgamma, rbeta, … but
    • many distributions of interest have no built-in generator (mixtures, truncated, multivariate, user-defined),
    • knowing how generators work tells you when they are efficient and when they fail.
  • Everything starts from Uniform(0,1) pseudo-random numbers.

Pseudo-Random Numbers

  • Computers produce deterministic sequences that look iid Uniform(0,1).
  • R’s default is the Mersenne-Twister (period \(2^{19937}-1\)); see ?RNGkind.
  • set.seed() makes a simulation reproducible.

The Inverse Transform Method

Probability integral transformation. If \(X\) is continuous with cdf \(F_X\), then \(U = F_X(X)\sim\text{Uniform}(0,1)\).

Define \(F_X^{-1}(u) = \inf\{x: F_X(x) = u\}\), \(0<u<1\). If \(U\sim\text{Uniform}(0,1)\), then

\[ P(F_X^{-1}(U)\le x) = P(U\le F_X(x)) = F_X(x), \]

so \(F_X^{-1}(U)\) has the same distribution as \(X\).

  1. Derive the inverse \(F_X^{-1}(u)\).
  2. Write a command or function to compute \(F_X^{-1}(u)\).
  3. For each random variate: generate \(u\) from Uniform(0,1) and deliver \(x = F_X^{-1}(u)\).

Example 3.2: Continuous Case

Simulate from \(f_X(x) = 3x^2\), \(0<x<1\). Here \(F_X(x) = x^3\), so \(F_X^{-1}(u) = u^{1/3}\).

set.seed(4750)

Inverse Transform: Discrete Case

If \(\cdots < x_{i-1} < x_i < \cdots\) are the points of discontinuity of \(F_X\), then \(F_X^{-1}(u) = x_i\) where \(F_X(x_{i-1}) < u \le F_X(x_i)\).

For each random variate: generate \(u\sim\) Uniform(0,1) and deliver \(x_i\) such that \(F(x_{i-1}) < u \le F(x_i)\).

Example 3.5: Geometric Distribution

\(f(x) = pq^x\), \(x = 0,1,2,\dots\) and \(F(x) = 1-q^{x+1}\). Solve \(1 - q^x < u \le 1 - q^{x+1}\):

\[ x = \lceil \log(1-u)/\log(q)\rceil - 1 \quad\Rightarrow\quad x = \lfloor \log(u)/\log(q)\rfloor\ \ (\text{since } 1-U\sim U) \]

Example 3.6: Logarithmic Distribution

\[ f(x) = \frac{a\,\theta^x}{x},\quad x = 1,2,\dots,\quad a = \big(-\log(1-\theta)\big)^{-1} \]

  • No closed-form inverse. Store the cdf on a grid; sum(u > F) + 1 counts how many \(F(x) < u\).
  • Compute \(f(x)\) as exp(log(a) + x*log(theta) - log(x)) for numerical accuracy.
rlogarithmic <- function(n, theta) {
  u <- runif(n)
  N <- ceiling(-16 / log10(theta))               # initial length of cdf vector
  k <- 1:N
  a <- -1 / log(1 - theta)
  fk <- exp(log(a) + k * log(theta) - log(k))
  Fk <- cumsum(fk)
  x <- integer(n)
  for (i in 1:n) {
    x[i] <- as.integer(sum(u[i] > Fk))           # F^{-1}(u) - 1
    while (x[i] == N) {                          # extend the cdf if needed
      logf <- log(a) + (N + 1) * log(theta) - log(N + 1)
      fk <- c(fk, exp(logf)); Fk <- c(Fk, Fk[N] + fk[N + 1]); N <- N + 1
      x[i] <- as.integer(sum(u[i] > Fk))
    }
  }
  x + 1
}

The Acceptance-Rejection Method

The Acceptance-Rejection Method

Suppose \(X\) has density (pmf) \(f\), \(Y\) has density \(g\), and there is a constant \(c\) with

\[ \frac{f(t)}{g(t)} \le c\quad\text{for all } t \text{ with } f(t) > 0. \]

  1. Find \(Y\sim g\) (easy to generate) with \(f(t)/g(t)\le c\).
  2. For each variate required:
    1. Generate \(y\) from \(g\).
    2. Generate \(u\) from Uniform(0,1).
    3. If \(u < f(y)/(c\,g(y))\), accept \(y\) and deliver \(x = y\); otherwise reject \(y\) and repeat from 2a.

Why It Works, and How Efficient It Is

  • \(P(\text{accept}\mid Y) = P\big(U < \tfrac{f(Y)}{cg(Y)}\mid Y\big) = \dfrac{f(Y)}{cg(Y)}\)
  • Overall acceptance probability: \(\displaystyle\sum_y \frac{f(y)}{cg(y)}g(y) = \frac1c\)
  • Number of iterations until acceptance \(\sim\) Geometric with mean \(c\) \(\Rightarrow\) want \(c\) small.
  • Bayes: \(P(k\mid\text{accepted}) = \dfrac{P(\text{accepted}\mid k)g(k)}{P(\text{accepted})} = \dfrac{[f(k)/(cg(k))]g(k)}{1/c} = f(k)\).

Example 3.7: Beta(2, 2) by Acceptance-Rejection

\(f(x) = 6x(1-x)\), \(0<x<1\). Take $g = $ Uniform(0,1); then \(f(x)/g(x)\le 6\), so \(c = 6\) works (the optimal \(c\) is \(1.5\)). Accept \(x\) if

\[ \frac{f(x)}{cg(x)} = \frac{6x(1-x)}{6(1)} = x(1-x) > u. \]

set.seed(4750)
n <- 1000; k <- 0; j <- 0; y <- numeric(n)
while (k < n) {
  u <- runif(1)
  j <- j + 1
  x <- runif(1)                 # random variate from g
  if (x * (1 - x) > u) {        # we accept x
    k <- k + 1
    y[k] <- x
  }
}
j                               # iterations: expect about c * n = 6000
[1] 5880

A Vectorized Acceptance-Rejection

rAR <- function(n, f, rg, dg, c) {
  out <- numeric(0); tries <- 0
  while (length(out) < n) {
    m <- ceiling(1.2 * c * (n - length(out)))      # propose in batches
    y <- rg(m); u <- runif(m); tries <- tries + m
    out <- c(out, y[u < f(y) / (c * dg(y))])
  }
  structure(out[1:n], acceptance = n / tries)
}
set.seed(4750)
z <- rAR(1e4, f = function(x) 6 * x * (1 - x), rg = runif, dg = dunif, c = 1.5)
attr(z, "acceptance")             # close to 1/c = 0.667
[1] 0.5556

Lecture B: Transformations, Mixtures, Multivariate

Transformation Methods

Many distributions are related by transformations:

  1. \(Z\sim N(0,1)\Rightarrow V = Z^2\sim\chi^2(1)\).
  2. \(U\sim\chi^2(m)\), \(V\sim\chi^2(n)\) independent \(\Rightarrow F = \dfrac{U/m}{V/n}\sim F(m,n)\).
  3. \(Z\sim N(0,1)\), \(V\sim\chi^2(n)\) independent \(\Rightarrow T = \dfrac{Z}{\sqrt{V/n}}\sim t(n)\).
  4. \(U, V\stackrel{\text{iid}}{\sim}\) Uniform(0,1) \(\Rightarrow\) (Box-Muller) \[ Z_1 = \sqrt{-2\log U}\cos(2\pi V),\quad Z_2 = \sqrt{-2\log U}\sin(2\pi V)\ \ \stackrel{\text{iid}}{\sim}N(0,1). \]
  5. \(U\sim\text{Gamma}(r,\lambda)\), \(V\sim\text{Gamma}(s,\lambda)\) independent \(\Rightarrow X = \dfrac{U}{U+V}\sim\text{Beta}(r,s)\).

Sums (Convolutions) and Mixtures

  • Convolution: \(S = X_1 + \cdots + X_n\) for independent \(X_j\); e.g. \(\chi^2(\nu)\), Gamma\((n,\lambda)\) = sum of exponentials, NegBin\((r,p)\) = sum of geometrics.
  • Mixture: \(F_X(x) = \sum_i \theta_i F_{X_i}(x)\) with \(\theta_i > 0\), \(\sum\theta_i = 1\) (discrete mixture), or \(F_X(x) = \int F_{X\mid Y=y}(x) f_Y(y)\,dy\) (continuous mixture).

A convolution adds the random variables; a mixture averages the distributions. To generate a mixture: first draw the component label, then draw from that component.

Example 3.11: Convolution vs. Mixture

\(X_1\sim\text{Gamma}(2,2)\), \(X_2\sim\text{Gamma}(2,4)\); compare \(S = X_1 + X_2\) with \(F_X = 0.5F_{X_1} + 0.5F_{X_2}\).

Multivariate Distributions

Generating Multivariate Normal Vectors

If \(\mathbf{Z}\sim N_d(\mathbf 0,\mathbf{I}_d)\) and \(\boldsymbol \Sigma= \mathbf C\mathbf C^\text{T}\), then \(\mathbf{X}= \mathbf C\mathbf{Z}+ \boldsymbol \mu\sim N_d(\boldsymbol \mu,\boldsymbol \Sigma)\). For a matrix of \(n\) rows:

\[ \mathbf{X}= \mathbf{Z}\,\mathbf Q + \mathbf J\boldsymbol \mu^\text{T},\qquad \mathbf Q^\text{T}\mathbf Q = \boldsymbol \Sigma. \]

Three factorizations of \(\boldsymbol \Sigma\):

Method Factorization R
Spectral (Ex 3.16) <U+03A3> = P <U+039B> P<U+1D40>, Q = P <U+039B>^<U+00BD> P<U+1D40> eigen()
SVD (Ex 3.17) <U+03A3> = U D V<U+1D40>, Q = U D^<U+00BD> V<U+1D40> svd()
Choleski (Ex 3.18) <U+03A3> = Q<U+1D40> Q, Q upper triangular chol()

Examples 3.16 - 3.18: Three Generators

rmvn.eigen <- function(n, mu, Sigma) {
  d <- length(mu); ev <- eigen(Sigma, symmetric = TRUE)
  Q <- ev$vectors %*% diag(sqrt(ev$values)) %*% t(ev$vectors)
  Z <- matrix(rnorm(n * d), nrow = n, ncol = d)
  Z %*% Q + matrix(mu, n, d, byrow = TRUE)
}
rmvn.svd <- function(n, mu, Sigma) {
  d <- length(mu); S <- svd(Sigma)
  Q <- S$u %*% diag(sqrt(S$d)) %*% t(S$v)
  Z <- matrix(rnorm(n * d), nrow = n, ncol = d)
  Z %*% Q + matrix(mu, n, d, byrow = TRUE)
}
rmvn.Choleski <- function(n, mu, Sigma) {
  d <- length(mu); Q <- chol(Sigma)       # Choleski factorization of Sigma
  Z <- matrix(rnorm(n * d), nrow = n, ncol = d)
  Z %*% Q + matrix(mu, n, d, byrow = TRUE)
}
mu <- c(0, 1, 2); Sigma <- matrix(c(1, -.5, .5, -.5, 1, -.5, .5, -.5, 1), 3)

Example 3.21: Uniform on the Sphere

If \(\mathbf{Z}\sim N_d(\mathbf 0,\mathbf{I}_d)\), then \(\mathbf{Z}/\|\mathbf{Z}\|\) is uniformly distributed on the unit sphere \(S^{d-1}\).

runif.sphere <- function(n, d) {
  M <- matrix(rnorm(n * d), nrow = n, ncol = d)
  L <- function(x) sqrt(sum(x * x))      # length of a vector
  M / apply(M, 1, L)
}
set.seed(4750)
par(mfrow = c(1, 2))
X <- runif.sphere(200, 2); plot(X, asp = 1, pch = 19, cex = .6, col = "#003366", main = "d = 2")
X <- runif.sphere(2000, 3)
scatterplot <- function(X) {                     # a rotated 2-d view of the 3-d points
  R <- qr.Q(qr(matrix(c(1, 2, 3, 0, 1, -1, 1, 0, 0), 3)))
  P <- X %*% R; plot(P[, 1:2], asp = 1, pch = 20, cex = .5, col = ifelse(P[, 3] > 0, "#C2185B", "gray70"),
                     main = "d = 3 (front hemisphere in pink)")
}
scatterplot(X)

Python Supplement: Generators in numpy

import numpy as np
rng = np.random.default_rng(4750)
u = rng.uniform(size=5000)
x = -np.log(u) / 2                                   # inverse transform: Exp(rate = 2)
Sigma = np.array([[1, .8], [.8, 1]])
Z = rng.standard_normal((5000, 2))
X = Z @ np.linalg.cholesky(Sigma).T                   # Choleski: rows ~ N(0, Sigma)
print(x.mean(), np.cov(X, rowvar=False))

Summary

  • Inverse transform: \(X = F^{-1}(U)\); discrete: \(x_i\) with \(F(x_{i-1}) < u\le F(x_i)\).
  • Acceptance-rejection: propose from \(g\), accept with probability \(f/(cg)\); expected \(c\) proposals per variate.
  • Transformations: Box-Muller, \(\chi^2\), \(t\), \(F\), beta from gammas.
  • Sums vs. mixtures: add random variables vs. average distributions.
  • Multivariate normal: \(\mathbf{Z}\mathbf Q + \boldsymbol \mu\) with spectral, SVD, or Choleski factor; normalize normals for the sphere.
  • Always validate a generator: histogram + density, QQ-plot, moments, frequency tables with SEs.
