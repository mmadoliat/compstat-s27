Optimization Is Everywhere in Statistics

  • Maximum likelihood: \(\hat\theta = \mathop{\mathrm{arg\,max}}_\theta\ell(\theta)\)
  • Least squares, ridge, lasso: \(\mathop{\mathrm{arg\,min}}_\beta\ \text{RSS} + \lambda\,\text{penalty}\)
  • K-means: \(\mathop{\mathrm{arg\,min}}_{C, c}\sum_k\sum_{C(i)=k}\|X_i - c_k\|^2\)
  • Neural networks: minimize a loss over millions of weights
  • Bandwidth selection: minimize UCV\((h)\)

R’s toolbox: optimize() (1-d), optim() (Nelder-Mead, BFGS, CG, L-BFGS-B, SANN, Brent), nlm(), nlminb(), constrOptim(), boot::simplex() (linear programming).

Example 14.1: One-Dimensional Optimization

Maximize \(f(x) = \dfrac{\log(x + \log x)}{\log(1+x)}\).

f <- function(x) log(x + log(x)) / log(1 + x)

opt <- optimize(f, lower = 4, upper = 8, maximum = TRUE)

Golden-Section Search by Hand

Keep a bracket \([a,b]\) and two interior points at the golden ratio \(\phi = (\sqrt5 - 1)/2\); each step discards a fraction \(1-\phi\approx 0.382\) of the bracket using one new function evaluation.

golden <- function(f, a, b, tol = 1e-8) {
  phi <- (sqrt(5) - 1) / 2; x1 <- b - phi * (b - a); x2 <- a + phi * (b - a); f1 <- f(x1); f2 <- f(x2); k <- 0
  while (b - a > tol) {
    k <- k + 1
    if (f1 > f2) { b <- x2; x2 <- x1; f2 <- f1; x1 <- b - phi * (b - a); f1 <- f(x1) }   # maximize
    else         { a <- x1; x1 <- x2; f1 <- f2; x2 <- a + phi * (b - a); f2 <- f(x2) }
  }
  c(maximum = (a + b) / 2, iterations = k)
}
golden(f, 4, 8)
   maximum iterations 
     5.792     42.000

Newton’s Method and Its Relatives

To maximize \(\ell(\theta)\), solve \(\nabla\ell(\theta) = \mathbf 0\) with Newton’s method:

\[ \theta_{k+1} = \theta_k - \big[\nabla^2\ell(\theta_k)\big]^{-1}\nabla\ell(\theta_k). \]

Method Uses Convergence Cost per step
Gradient ascent \(\nabla\ell\) linear cheap
Newton-Raphson \(\nabla\ell\), \(\nabla^2\ell\) quadratic (near optimum) Hessian + solve
Fisher scoring \(\nabla\ell\), \(\mathcal I(\theta)\) ~quadratic expected information
Quasi-Newton (BFGS) \(\nabla\ell\), Hessian approximation superlinear cheap updates
Nelder-Mead \(\ell\) only slow, robust function evaluations

Gradient Descent vs. Newton on a Quadratic

A <- matrix(c(3, 1.4, 1.4, 1), 2); b <- c(1, 1)
fq <- function(x) 0.5 * sum(x * (A %*% x)) - sum(b * x)        # minimum at solve(A, b)
gq <- function(x) as.vector(A %*% x - b)
gd <- function(x, step = 0.25, n = 40) { path <- x; for (k in 1:n) { x <- x - step * gq(x); path <- rbind(path, x) }; path }
nt <- function(x, n = 2) { path <- x; for (k in 1:n) { x <- x - solve(A, gq(x)); path <- rbind(path, x) }; path }
g1 <- seq(-3, 3, length = 100); z <- outer(g1, g1, Vectorize(function(u, v) fq(c(u, v))))
contour(g1, g1, z, nlevels = 25, col = "gray60", asp = 1, xlab = expression(theta[1]), ylab = expression(theta[2]))

Example 14.2: MLE for the Gamma Distribution

\[ \ell(r,\lambda) = nr\log\lambda + (r-1)\sum\log x_i - \lambda\sum x_i - n\log\Gamma(r). \]

Setting \(\partial\ell/\partial\lambda = 0\) gives \(\lambda = r/\bar x\); substituting, \(r\) solves the one-dimensional equation

\[ \log r - \psi(r) = \log\bar x - \overline{\log x}\qquad(\psi = \text{digamma}). \]

set.seed(4750); m <- 2000; est <- matrix(0, m, 2); n <- 200; r <- 5; lambda <- 2
obj <- function(r, x) log(r) - digamma(r) - (log(mean(x)) - mean(log(x)))
for (i in 1:m) {
  x <- rgamma(n, shape = r, rate = lambda)
  u <- uniroot(obj, lower = .001, upper = 10e5, x = x)
  est[i, ] <- c(u$root, u$root / mean(x))
}
colMeans(est)              # close to (5, 2)
[1] 5.064 2.028

Example 14.3: Two-Dimensional Optimization with optim

LL <- function(theta, sx, slogx, n) {
  r <- theta[1]; lambda <- theta[2]
  loglik <- n * r * log(lambda) + (r - 1) * slogx - lambda * sx - n * log(gamma(r))
  -loglik
}
set.seed(4750); n <- 200; x <- rgamma(n, shape = 5, rate = 2)
optim(c(1, 1), LL, sx = sum(x), slogx = sum(log(x)), n = n)[c("par", "value", "counts", "convergence")]
$par

$value

function gradient 
      73       NA 

$convergence

  • Default method is Nelder-Mead (no derivatives). Try method = "BFGS" with an analytic gradient:
grLL <- function(theta, sx, slogx, n) {
  r <- theta[1]; lambda <- theta[2]
  -c(n * log(lambda) + slogx - n * digamma(r), n * r / lambda - sx)
}
fit <- optim(c(1, 1), LL, grLL, sx = sum(x), slogx = sum(log(x)), n = n, method = "L-BFGS-B",
             lower = c(1e-4, 1e-4), hessian = TRUE)
rbind(estimate = fit$par, se = sqrt(diag(solve(fit$hessian))))

estimate 4.6701 1.8795
se       0.4513 0.1918

Reparametrize Instead of Constraining

\(r, \lambda > 0\): optimize over \((\log r, \log\lambda)\in\mathbb{R}^2\); use lgamma() not log(gamma()) (Ch 13!).

LL2 <- function(eta, x) -sum(dgamma(x, shape = exp(eta[1]), rate = exp(eta[2]), log = TRUE))
fit2 <- optim(c(0, 0), LL2, x = x, method = "BFGS")
exp(fit2$par)
[1] 4.670 1.879

Good practice for optim: sensible starting values (MOM!), unconstrained parametrization, analytic gradients when available, check convergence == 0, and try more than one start.

Example 14.4: MLE for a Quadratic Form (a Mixture)

\(Y = \lambda_1X_1^2 + \cdots + \lambda_kX_k^2\) in distribution is an equal mixture of Gamma\(\big(\tfrac12, \tfrac1{2\lambda_j}\big)\) (here \(k = 3\), \(\sum\lambda_j = 1\)).

LL <- function(lambda, y) {
  lambda3 <- 1 - sum(lambda)
  f1 <- dgamma(y, shape = 1/2, rate = 1 / (2 * lambda[1]))
  f2 <- dgamma(y, shape = 1/2, rate = 1 / (2 * lambda[2]))
  f3 <- dgamma(y, shape = 1/2, rate = 1 / (2 * lambda3))
  f <- f1 / 3 + f2 / 3 + f3 / 3        # density of mixture
  return(-sum(log(f)))                 # returning -loglikelihood
}
set.seed(9); m <- 2000
lambda <- c(.6, .25, .15)              # rate is 1/(2lambda)
lam <- sample(lambda, size = 2000, replace = TRUE)
y <- rgamma(m, shape = .5, rate = 1 / (2 * lam))
opt <- optim(c(.5, .3), LL, y = y)
c(opt$par, 1 - sum(opt$par))
[1] 0.5890 0.2505 0.1605

Simulated Annealing (method = "SANN")

For rough or multimodal objectives, accept “uphill” moves with probability \(e^{-\Delta/T}\) and lower the temperature \(T\).

rough <- function(x) (x[1]^2 + x[2]^2) / 20 - cos(3 * x[1]) * cos(3 * x[2])   # many local minima
set.seed(4750)
starts <- matrix(runif(20, -4, 4), 10)
bfgs <- apply(starts, 1, function(s) optim(s, rough, method = "BFGS")$value)
sann <- apply(starts, 1, function(s) optim(s, rough, method = "SANN", control = list(maxit = 5000))$value)
boxplot(list(BFGS = bfgs, SANN = sann), horizontal = TRUE, col = c("#88A0C8", "#FFCC00"),
        main = "Final objective from 10 random starts (global min = -1)")

Example 14.6: The Simplex Algorithm

Maximize \(2x + 2y + 3z\) subject to \(-2x + y + z\le 1\), \(\ 4x - y + 3z\le 3\), \(\ x, y, z\ge 0\).

  • If an optimum exists, it is attained at a vertex of the feasible polytope; the simplex method moves from vertex to vertex in the direction of greatest increase.
library(boot)
A1 <- rbind(c(-2, 1, 1), c(4, -1, 3)); b1 <- c(1, 3); a <- c(2, 2, 3)
s <- simplex(a = a, A1 = A1, b1 = b1, maxi = TRUE)
s$soln; s$value

The solution is \((x, y, z) = (2, 5, 0)\) with value 14. Can you verify the two constraints are active?

Example 14.7: Solving the Morra Game

3-finger Morra: each player shows 1-3 fingers and guesses the opponent’s number; a correct guess wins the total shown. 9 pure strategies; a zero-sum game solved by two linear programs (one per player).

solve.game <- function(A) {
  min.A <- min(A); A <- A - min.A; max.A <- max(A); A <- A / max(A)   # so that v >= 0
  m <- nrow(A); n <- ncol(A); it <- n^3
  a <- c(rep(0, m), 1)                          # maximize v for player 1
  A1 <- -cbind(t(A), rep(-1, n)); b1 <- rep(0, n)
  A3 <- t(as.matrix(c(rep(1, m), 0))); b3 <- 1
  sx <- simplex(a = a, A1 = A1, b1 = b1, A3 = A3, b3 = b3, maxi = TRUE, n.iter = it)
  a <- c(rep(0, n), 1)                          # minimize v for player 2
  A1 <- cbind(A, rep(-1, m)); b1 <- rep(0, m)
  A3 <- t(as.matrix(c(rep(1, n), 0))); b3 <- 1
  sy <- simplex(a = a, A1 = A1, b1 = b1, A3 = A3, b3 = b3, maxi = FALSE, n.iter = it)
  list("A" = A * max.A + min.A, "x" = sx$soln[1:m], "y" = sy$soln[1:n], "v" = sx$soln[m + 1] * max.A + min.A)
}
A <- matrix(c(0, -2, -2, 3, 0, 0, 4, 0, 0,  2, 0, 0, 0, -3, -3, 4, 0, 0,  2, 0, 0, 3, 0, 0, 0, -4, -4,
             -3, 0, -3, 0, 4, 0, 0, 5, 0,  0, 3, 0, -4, 0, -4, 0, 5, 0,  0, 3, 0, 0, 4, 0, -5, 0, -5,
             -4, -4, 0, 0, 0, 5, 0, 0, 6,  0, 0, 4, -5, -5, 0, 0, 0, 6,  0, 0, 4, 0, 0, 5, -6, -6, 0), 9, 9)
sol <- solve.game(A)

Python Supplement: scipy.optimize

import numpy as np
from scipy import optimize, special, stats
x = stats.gamma(a=5, scale=1/2).rvs(size=200, random_state=4750)
def nll(eta):
    r, lam = np.exp(eta)
    return -np.sum(stats.gamma.logpdf(x, a=r, scale=1/lam))
fit = optimize.minimize(nll, x0=[0, 0], method="BFGS")
print(np.exp(fit.x))

Summary

  • 1-d: optimize() (golden section + parabolic interpolation); roots of the score: uniroot().
  • Multi-d: optim(); Nelder-Mead (default), BFGS/L-BFGS-B with gradients, SANN for rough surfaces.
  • Newton is fast near the optimum; gradient methods are cheap per step; quasi-Newton is the usual compromise.
  • Reparametrize to remove constraints, use log-scale functions, start from MOM.
  • Linear programs (boot::simplex): optima at vertices; zero-sum games.
