Resampling Methods: The Family

  • Bootstrap (Efron, 1979): resample \(n\) points with replacement from the data; estimate the sampling distribution of \(\hat\theta\).
  • Permutation tests: permute labels to obtain the null distribution of a test statistic (Rizzo Ch 10).
  • Jackknife (Quenouille, 1949; named by Tukey, 1956): leave out one observation at a time, i.e., resample without replacement, \(n-1\) points. Originally for bias correction; Tukey added variance estimates and approximate confidence limits.

Jackknife Samples and Replicates

  • The \(i\)th delete-1 jackknife sample: \(x_{(i)} = (x_1,\dots,x_{i-1},x_{i+1},\dots,x_n)\); there are exactly \(n\) of them.
  • The \(i\)th jackknife replicate: \(\hat\theta_{(i)} = s(x_{(i)})\); their average \(\bar{\hat\theta}_{(\cdot)} = \frac1n\sum_i\hat\theta_{(i)}\).

\[ \widehat\mathrm{bias}_{\text{jack}} = (n-1)\big(\bar{\hat\theta}_{(\cdot)} - \hat\theta\big),\qquad \widehat\mathrm{se}_{\text{jack}} = \sqrt{\frac{n-1}{n}\sum_{i=1}^n\big(\hat\theta_{(i)} - \bar{\hat\theta}_{(\cdot)}\big)^2}. \]

  • Deterministic: no random numbers, only \(n\) recomputations.

Why the Factor \((n-1)/n\)? The Sample Mean

For \(\hat\theta = \bar x\): \(\hat\theta_{(i)} = \dfrac{n\bar x - x_i}{n-1}\) and \(\bar{\hat\theta}_{(\cdot)} = \bar x\), so

\[ \hat\theta_{(i)} - \bar{\hat\theta}_{(\cdot)} = \frac{\bar x - x_i}{n-1} \quad\Rightarrow\quad \frac{n-1}{n}\sum_{i=1}^n\big(\hat\theta_{(i)}-\bar{\hat\theta}_{(\cdot)}\big)^2 = \frac{1}{n(n-1)}\sum_{i=1}^n(x_i-\bar x)^2 = \frac{S^2}{n}. \]

The jackknife SE of the mean is exactly the usual \(S/\sqrt n\).

set.seed(4750); x <- rexp(12); n <- length(x)
th.jack <- sapply(1:n, function(i) mean(x[-i]))
c(jackknife = sqrt((n - 1) / n * sum((th.jack - mean(th.jack))^2)), usual = sd(x) / sqrt(n))
jackknife     usual 
   0.1896    0.1896

Why the Factor \((n-1)\) in the Bias?

Suppose \(\mathrm{E}[\hat\theta_n] = \theta + \dfrac{b_1(\theta)}{n} + \dfrac{b_2(\theta)}{n^2} + \cdots\). Each replicate uses \(n-1\) points, so

\[ \mathrm{E}\big[\bar{\hat\theta}_{(\cdot)}\big] - \mathrm{E}[\hat\theta] = \frac{b_1}{n-1} - \frac{b_1}{n} + O(n^{-3}) = \frac{b_1}{n(n-1)} + O(n^{-3}). \]

Multiplying by \((n-1)\) estimates the leading bias \(b_1/n\). The bias-corrected estimator

\[ \hat\theta_{\text{jack}} = \hat\theta - \widehat\mathrm{bias}_{\text{jack}} = n\hat\theta - (n-1)\bar{\hat\theta}_{(\cdot)} \]

has bias \(O(n^{-2})\): the \(1/n\) term cancels.

Check: for \(\hat\theta = \frac1n\sum(x_i-\bar x)^2\) (bias \(-\sigma^2/n\)), \(\widehat\mathrm{bias}_{\text{jack}} = -S^2/n\) and \(\hat\theta_{\text{jack}} = S^2\).

pvar <- function(x) mean((x - mean(x))^2)
th.jack <- sapply(1:n, function(i) pvar(x[-i]))
c(bias_jack = (n - 1) * (mean(th.jack) - pvar(x)), minus_S2_over_n = -var(x) / n)
      bias_jack minus_S2_over_n 
       -0.03593        -0.03593

Example 8.8: Failure of the Jackknife

The jackknife can fail when the statistic is not smooth. Median of 10 integers:

n <- 10; set.seed(4750)
x <- sample(1:100, size = n)
M <- numeric(n)
for (i in 1:n) M[i] <- median(x[-i])
Mbar <- mean(M)
print(sort(M))                                   # only two distinct values!
 [1] 47 47 47 47 47 49 49 49 49 49
c(jackknife_se = sqrt((n - 1) / n * sum((M - Mbar)^2)),
  bootstrap_se = sd(replicate(1000, median(sample(x, replace = TRUE)))))
jackknife_se bootstrap_se 
        3.00         7.69

Fix for non-smooth statistics: the delete-\(d\) jackknife with \(\sqrt n < d < n-1\) (Shao and Wu, 1989): \(\widehat\mathrm{se}_{d\text{-jack}} = \left\{\frac{n-d}{d\binom nd}\sum_z\big(\hat\theta_{(z)} - \bar{\hat\theta}_{(\cdot)}\big)^2\right\}^{1/2}\).

Delete-\(d\) Jackknife for the Median

djack_se <- function(x, d, stat = median, maxsub = 5000) {
  n <- length(x)
  subs <- if (choose(n, d) <= maxsub) combn(n, d) else replicate(maxsub, sample(n, d))  # all or a random subset
  th <- apply(subs, 2, function(z) stat(x[-z]))
  sqrt((n - d) / d * mean((th - mean(th))^2))
}
set.seed(4750); x <- rnorm(40)
c(delete1 = djack_se(x, 1), delete10 = djack_se(x, 10),
  bootstrap = sd(replicate(2000, median(sample(x, replace = TRUE)))),
  asymptotic = sqrt(pi / 2) / sqrt(40))
   delete1   delete10  bootstrap asymptotic 
   0.05027    0.26787    0.26189    0.19817

Pseudovalues

\[ \tilde\theta_i = n\hat\theta - (n-1)\hat\theta_{(i)},\qquad \hat\theta_{\text{jack}} = \frac1n\sum_i\tilde\theta_i,\qquad \widehat\mathrm{se}_{\text{jack}} = \frac{s_{\tilde\theta}}{\sqrt n}. \]

  • Tukey: treat pseudovalues as if they were iid; a \(t\)-type interval \(\hat\theta_{\text{jack}}\pm t_{n-1}\,\widehat\mathrm{se}_{\text{jack}}\).
  • Efron and Tibshirani: this interval is not much better than normal theory; prefer bootstrap intervals.
n <- nrow(patch); pseudo <- n * theta.hat - (n - 1) * theta.jack
c(theta_jack = mean(pseudo), se = sd(pseudo) / sqrt(n))
theta_jack         se 
  -0.07931    0.10553

Example: Estimating the Upper Bound of a Uniform

\(X\sim U(0,\theta)\), \(\hat\theta = X_{(n)}\) with \(\mathrm{E}X_{(n)} = \frac{n}{n+1}\theta\) (biased). Here \(\bar{\hat\theta}_{(\cdot)} = \frac{n-1}{n}X_{(n)} + \frac1nX_{(n-1)}\), so

\[ \hat\theta_{\text{jack}} = X_{(n)} + \frac{n-1}{n}\big(X_{(n)} - X_{(n-1)}\big). \]

set.seed(4750); N <- 20000
res <- sapply(c(10, 30, 100), function(n) {
  r <- replicate(N, { s <- sort(runif(n, 0, 5)); mx <- s[n]; jk <- mx + (n - 1) / n * (mx - s[n - 1])
                      c(abs(5 - jk) < abs(5 - mx), abs(5 - jk), abs(5 - mx)) })
  rowMeans(r)
})
dimnames(res) <- list(c("P(|jack err| < |max err|)", "mean |jack - 5|", "mean |max - 5|"), c("n=10", "n=30", "n=100"))
round(res, 4)
                            n=10   n=30  n=100
P(|jack err| < |max err|) 0.6948 0.6762 0.6682
mean |jack - 5|           0.4343 0.1575 0.0498
mean |max - 5|            0.4588 0.1605 0.0503
  • McIntosh’s simulation: the jackknife estimate is closer about 68% of the time. Of course (n+1)/n * max is exactly unbiased here, but the jackknife does not need to know the distribution.

Jackknife vs. Bootstrap

  • Efron and Tibshirani: the jackknife variance estimate is \(\frac{n}{n-1}\) times the bootstrap variance of a linear approximation \(T_{\text{LIN}}(\mathbf P^*) = c_0 + (\mathbf P^* - \mathbf P_0)^\text{T}\mathbf U\) to the statistic, where \(\mathbf P^*\) is the vector of resampling proportions.
  • So the jackknife is excellent for smooth (nearly linear) statistics and poor for non-smooth ones (median, quantiles).
  • It assumes iid data: not for time series or correlated data without modification (block jackknife).
Jackknife Bootstrap
Resamples \(n\) deterministic \(B\) random
Bias, SE yes (smooth statistics) yes
Confidence intervals rough yes (percentile, BCa, \(t\))
Non-smooth statistics fails (delete-1) works
Used for BCa acceleration, influence, JaB most inference

Jackknife-after-Bootstrap (Rizzo 9.1)

How Accurate Is \(\widehat{\mathrm{se}}_B\)?

\(\widehat\mathrm{se}_B(\hat\theta)\) is itself random. To estimate its standard error, leave out \(x_i\), and recompute \(\widehat\mathrm{se}_B\) using only the bootstrap samples that do not contain \(x_i\): no new resampling!

  • \(J(i)\) = indices of bootstrap samples not containing \(x_i\); \(B(i) = |J(i)|\).

\[ \widehat\mathrm{se}_{B(i)} = \sqrt{\frac{1}{B(i)}\sum_{j\in J(i)}\big[\hat\theta^{(j)} - \bar{\hat\theta}_{(J(i))}\big]^2},\qquad \widehat\mathrm{se}\big(\widehat\mathrm{se}_B\big) = \widehat\mathrm{se}_{\text{jack}}\big(\widehat\mathrm{se}_{B(1)},\dots,\widehat\mathrm{se}_{B(n)}\big). \]

  • On average \(B(i)\approx B(1-1/n)^n\approx 0.37B\).

Resampling for Regression Models (Rizzo 9.2)

Two Ways to Bootstrap a Regression

Resampling cases (pairs)

  • Resample rows \((x_i, y_i)\) with replacement; refit.
  • Robust to heteroscedasticity and model misspecification.
  • Treats \(X\) as random.

Resampling errors (residuals)

  • Fit; resample residuals \(\hat e_j^*\); set \(y_i^* = \hat y_i + \hat e^*_i\); refit.
  • Treats \(X\) as fixed; assumes the model and iid errors.
  • Use modified residuals \(r_i = \hat e_i/\sqrt{1-h_{ii}}\) (centered).

Examples 9.7 - 9.9: Resampling (Modified) Errors

y <- log(mammals$brain); x <- log(mammals$body)
L <- lm(y ~ x); n <- length(y)
r <- residuals(L) / sqrt(1 - hatvalues(L)); r <- r - mean(r)     # modified, centered residuals
set.seed(4750); m <- 2000; estsE <- numeric(m)
for (b in 1:m) {
  ystar <- fitted(L) + sample(r, replace = TRUE)
  estsE[b] <- coef(lm(ystar ~ x))[2]
}
model_based <- function(dat, i) { ystar <- dat$fit + dat$r[i]; coef(lm(ystar ~ dat$x))[2] }
dat <- data.frame(x = x, fit = fitted(L), r = r)
set.seed(4750); boot.err <- boot(dat, model_based, R = 2000)
c(slope = coef(L)[2], se_lm = summary(L)$coef[2, 2], se_errors = sd(estsE), se_boot_fn = sd(boot.err$t))
   slope.x      se_lm  se_errors se_boot_fn 
   0.75169    0.02846    0.02868    0.02820

Influence (Rizzo 9.3)

  • The empirical influence value of \(x_i\) measures how much \(\hat\theta\) changes when \(x_i\) is up-weighted; the jackknife approximation is \(l_{\text{jack},i} = (n-1)(\hat\theta - \hat\theta_{(i)})\).
  • \(\sum_i l_i^2/n^2\) approximates \(\mathrm{Var}(\hat\theta)\) (the nonparametric delta method).

Summary

  • Jackknife: \(n\) leave-one-out replicates; \(\widehat\mathrm{bias}= (n-1)(\bar{\hat\theta}_{(\cdot)}-\hat\theta)\), \(\widehat\mathrm{se}= \sqrt{\tfrac{n-1}{n}\sum(\hat\theta_{(i)}-\bar{\hat\theta}_{(\cdot)})^2}\).
  • Exact for the mean; removes \(O(1/n)\) bias; fails for non-smooth statistics (use delete-\(d\) or the bootstrap).
  • Jackknife-after-bootstrap: SE of bootstrap estimates and influence diagnostics with no extra resampling.
  • Regression: resample cases (robust) or errors (model-based, use modified residuals).
