Lecture A: K-Means Clustering

Don’t Confuse Clustering and Classification!

Classification (supervised)

  • Data whose groups are known
  • Learn what differentiates the groups (a classification function) to classify future data
  • e.g. handwritten digits 0-9 with labels

Clustering (unsupervised)

  • Groups are unknown and undefined
  • Learn the groups themselves, as well as what differentiates them

Dissimilarity and Within-Cluster Scatter

  • Observations \(X_1,\dots,X_n\) and dissimilarities \(d(X_i,X_j)\), e.g. \(X_i\in\mathbb{R}^p\) and \(d(X_i,X_j) = \|X_i - X_j\|_2^2\).
  • A clustering \(C\) assigns each \(X_i\) to a group \(C(i) = k\in\{1,\dots,K\}\); \(n_k\) points in group \(k\); \(d_{ij} = d(X_i,X_j)\).

The within-cluster scatter is

\[ W = \frac12\sum_{k=1}^K\frac1{n_k}\sum_{C(i)=k,\,C(j)=k} d_{ij}. \]

Smaller \(W\) is better.

Finding the Best Group Assignments

Why not search over all clusterings \(C\)? The number of possible assignments of \(n\) points into \(K\) nonempty groups is

\[ A(n,K) = \frac1{K!}\sum_{k=1}^K(-1)^{K-k}\binom Kk k^n . \]

A <- function(n, K) sum((-1)^(K - (1:K)) * choose(K, 1:K) * (1:K)^n) / factorial(K)
c(A(10, 4), A(25, 4))
[1] 3.410e+04 4.677e+13
  • \(A(10,4) = 34{,}105\) and \(A(25,4)\approx 5\times10^{13}\): hopeless for realistic \(n\). We settle for an approximation.

Rewriting the Within-Cluster Scatter

For Euclidean data and \(d_{ij} = \|X_i - X_j\|_2^2\):

\[ \frac12\sum_{k=1}^K\frac1{n_k}\sum_{C(i)=k}\sum_{C(j)=k}\|X_i-X_j\|_2^2 = \sum_{k=1}^K\sum_{C(i)=k}\|X_i-\bar X_k\|_2^2, \]

where \(\bar X_k = \frac1{n_k}\sum_{C(i)=k}X_i\). The right-hand side is the within-cluster variation.

cl <- c(1, 1, 2, 2, 2)

Rewriting the Minimization

  • For any \(Z_1,\dots,Z_m\), \(\sum_i\|Z_i - c\|_2^2\) is minimized by \(c = \bar Z\).
  • So minimizing the within-cluster variation is the same as minimizing the enlarged criterion

\[ \sum_{k=1}^K\sum_{C(i)=k}\|X_i - c_k\|_2^2 \quad\text{over both } C \text{ and } c_1,\dots,c_K\in\mathbb{R}^p. \]

The K-Means Algorithm

Start with an initial guess for \(c_1,\dots,c_K\) (e.g. \(K\) random points). Repeat:

  1. Minimize over \(C\): for each \(i\), find the closest center \(c_k\) to \(X_i\) and let \(C(i) = k\).
  2. Minimize over \(c_1,\dots,c_K\): for each \(k\), let \(c_k = \bar X_k\), the average of points in group \(k\).

Stop when the within-cluster variation does not change.

In words: (1) label each point by its closest center; (2) replace each center by the average of its points.

K-Means from Scratch

my_kmeans <- function(X, K, centers = X[sample(nrow(X), K), , drop = FALSE], maxit = 50) {
  history <- list(centers)
  for (it in 1:maxit) {
    d <- sapply(1:K, function(k) colSums((t(X) - centers[k, ])^2))   # n x K squared distances
    cl <- max.col(-d)                                                  # step 1: closest center
    new <- t(sapply(1:K, function(k) colMeans(X[cl == k, , drop = FALSE])))   # step 2: averages
    history[[it + 1]] <- new
    if (all(abs(new - centers) < 1e-10)) break
    centers <- new
  }
  wcv <- sum(sapply(1:K, function(k) sum(sweep(X[cl == k, , drop = FALSE], 2, centers[k, ])^2)))
  list(cluster = cl, centers = centers, wcv = wcv, iter = it, history = history)
}

K-Means Example: \(n = 300\), \(K = 3\)

set.seed(1)

       main = if (it == 1) "Initial centers" else paste("Iteration", it - 1))
  points(cen, pch = 19, cex = 2.5, col = cols)
}

Properties of K-Means

  • Within-cluster variation decreases with each iteration: if \(W_t\) is the value at iteration \(t\), then \(W_{t+1}\le W_t\).
  • The algorithm always converges, no matter the initial centers. (In at most \(K^n\) iterations. Why?)
  • The final clustering depends on the initial centers. Run K-means multiple times (e.g. 10 random starts) and keep the solution with the smallest within-cluster variation.
  • K-means is not guaranteed to find the global minimizer (that would require all \(A(n,K)\) assignments!).

Lecture B: Hierarchical Clustering

From K-Means to Hierarchical Clustering

Recall two properties of K-means (K-medoids):

  1. It fits exactly \(K\) clusters (as specified).
  2. The final assignment depends on the chosen initial centers.

Given pairwise dissimilarities \(d_{ij}\), hierarchical clustering produces a consistent result without choosing initial positions or the number of clusters.

  • The catch: we must choose a way to measure dissimilarity between groups, called the linkage.
  • The result is a sequence of clusterings: at one end all points are in their own cluster, at the other end all points are in one cluster.

Agglomerative vs. Divisive

Agglomerative (bottom-up)

  • Start with all points in their own group
  • Until there is only one cluster, repeatedly merge the two groups with the smallest dissimilarity

Divisive (top-down)

  • Start with all points in one cluster
  • Until all points are in their own cluster, repeatedly split the group into two, resulting in the biggest dissimilarity

Agglomerative strategies are simpler; we focus on them (hclust()). Divisive: cluster::diana().

What’s a Dendrogram?

A tree that displays the hierarchical sequence of clusterings:

  • Each node represents a group; each leaf is a singleton; the root contains the whole data set.
  • Each internal node has two daughters: the groups that were merged to form it.
  • With leaves at height zero, each internal node is drawn at a height proportional to the dissimilarity between its two daughters.
  • Cutting the dendrogram horizontally partitions the data into clusters: cutree(hc, h = ) or cutree(hc, k = ).

Linkages

  • Points \(X_1,\dots,X_n\), dissimilarities \(d_{ij}\) (here \(d_{ij} = \|X_i - X_j\|_2\), distance not squared).
  • Groups \(G, H\subseteq\{1,\dots,n\}\). A linkage is a function \(d(G,H)\) returning a dissimilarity score between groups.

Agglomerative clustering: start with all points in their own group; until there is only one cluster, merge the two groups \(G, H\) with the smallest \(d(G,H)\).

Single Linkage

Nearest-neighbor linkage: the smallest dissimilarity between two points in opposite groups, \[ d_{\text{single}}(G,H) = \min_{i\in G,\,j\in H}d_{ij}. \]

Cut interpretation: for each point \(X_i\), there is another point \(X_j\) in its cluster with \(d_{ij}\le 0.9\).

Complete Linkage

Furthest-neighbor linkage: the largest dissimilarity between two points in opposite groups, \[ d_{\text{complete}}(G,H) = \max_{i\in G,\,j\in H}d_{ij}. \]

Cut interpretation: for each point \(X_i\), every other point \(X_j\) in its cluster satisfies \(d_{ij}\le 5\).

Average Linkage

The average dissimilarity over all pairs in opposite groups, \[ d_{\text{average}}(G,H) = \frac1{n_G\cdot n_H}\sum_{i\in G,\,j\in H}d_{ij}. \]

Cut interpretation: there really isn’t a good one!

Shortcomings of Single, Complete, and Average Linkage

  • Single linkage suffers from chaining: to merge two groups, only one pair of points needs to be close. Clusters can be too spread out, not compact enough.
  • Complete linkage avoids chaining but suffers from crowding: a point can be closer to points in other clusters than to points in its own cluster.
  • Average linkage strikes a balance (relatively compact and relatively far apart), but
    • it is not clear what properties the clusters have when we cut the tree, and
    • results can change with a monotone increasing transformation of the \(d_{ij}\) (single and complete are unchanged).

for (pw in 1:2) plot(X60, col = c("#C0392B", "#2E5BBA", "#27AE60")[cutree(hclust(d60^pw, "average"), k = 3)],
                     pch = 1, lwd = 2, main = c("Avg linkage: distance", "Avg linkage: distance^2")[pw])

Centroid Linkage

Commonly used in biology (Eisen et al., 1998). With group averages \(\bar X_G\), \(\bar X_H\): \[ d_{\text{centroid}}(G,H) = \|\bar X_G - \bar X_H\|_2. \]

hc_c <- hclust(d60^2, method = "centroid")      # R's centroid method expects squared distances
sum(diff(hc_c$height) < 0)                      # number of inversions in the merge heights
[1] 5
par(mar = c(1, 4, 1, 1)); plot(hc_c, labels = FALSE, main = "", xlab = "", sub = "")
  • Simple, but can produce dendrograms with inversions (a merge lower than the previous one), there is no cut interpretation, and answers change under monotone transformations.

Minimax Linkage

Define the radius of a group around \(X_i\) as \(r(X_i, G) = \max_{j\in G}d_{ij}\). Then \[ d_{\text{minimax}}(G,H) = \min_{i\in G\cup H}r(X_i, G\cup H), \] the smallest radius encompassing all points in \(G\) and \(H\); the minimizer \(X_c\) is the prototype (Bien and Tibshirani, 2011).

  • Cut interpretation: each point is within \(h\) of the center (a data point!) of its cluster.
  • No inversions; unchanged by monotone transformations; the hierarchical analogue of K-medoids.
hc_mm <- protoclust::protoclust(d60)
plot(hc_mm, labels = FALSE, main = "Minimax linkage (protoclust)", xlab = "", sub = "")

How Many Clusters?

This Is a Hard Problem

  • Sometimes \(K\) is known ahead of time (segment customers for \(K\) salespeople; vector quantization with \(K\) codewords).
  • Other times \(K\) is implicitly defined by cutting a tree at a given height.
  • In most exploratory applications \(K\) is unknown. What is the “right” value of \(K\)?

Why is it hard? It is hard for humans to perform (unless the data are low-dimensional) and just as hard to explain what we are looking for. Why is it important? E.g., \(K=2\) vs. \(K=3\) subtypes of breast cancer is a big scientific difference.

Within-Cluster Variation Just Keeps Decreasing

\[ W(K) = \sum_{k=1}^K\sum_{C(i)=k}\|X_i - \bar X_k\|_2^2 \]

set.seed(4750)
fits <- lapply(1:10, function(k) kmeans(X250, k, nstart = 20))
Wk <- sapply(fits, `[[`, "tot.withinss"); Bk <- sapply(fits, `[[`, "betweenss")
par(mfrow = c(1, 2))
plot(X250, pch = 20, col = "gray50"); points(fits[[4]]$centers, pch = 19, cex = 2.5, col = cols4)
plot(1:10, Wk, type = "b", pch = 19, xlab = "K", ylab = "Within-cluster variation")

Between-Cluster Variation

\[ B(K) = \sum_{k=1}^K n_k\|\bar X_k - \bar X\|_2^2,\qquad \bar X = \frac1n\sum_{i=1}^nX_i \]

  • Bigger \(B\) is better, but \(B(K)\) just keeps increasing with \(K\).
  • Note \(W(K) + B(K) = \text{TSS}\), constant!
plot(1:10, Bk, type = "b", pch = 19, xlab = "K", ylab = "Between-cluster variation")

The CH Index (Calinski and Harabasz, 1974)

We want simultaneously a small \(W\) and a large \(B\):

\[ \text{CH}(K) = \frac{B(K)/(K-1)}{W(K)/(n-K)},\qquad \hat K = \mathop{\mathrm{arg\,max}}_{K\in\{2,\dots,K_{\max}\}}\text{CH}(K). \]

n <- nrow(X250); K <- 2:10
CH <- (Bk[K] / (K - 1)) / (Wk[K] / (n - K))
par(mfrow = c(1, 2))
plot(X250, pch = 20, col = adjustcolor(cols4[fits[[4]]$cluster], .5))
plot(K, CH, type = "b", pch = 19, xlab = "K", ylab = "CH index"); abline(v = K[which.max(CH)], lty = 2, col = 2)
  • We would choose \(K = 4\). Problem: CH is not defined for \(K = 1\), so it can never choose “no clusters”.

  • The gap statistic (Tibshirani, Walther, Hastie 2001) compares log W(K) with its expectation under a reference (uniform) distribution, and can choose K = 1.

Summary

  • K-means: minimize within-cluster variation by alternating assignments and averages; use many random starts and standardize variables.
  • K-medoids (PAM): centers are data points; any dissimilarity.
  • Hierarchical: one tree, many clusterings; the linkage matters (single, complete, average, centroid, minimax, Ward).
  • Choosing \(K\): elbow of \(W(K)\), CH index, silhouette, gap statistic. No universal answer.
