Computational Statistics vs. Statistical Computing

Statistical computing

  • Numerical methods inside statistical software
  • Floating-point arithmetic, linear algebra, optimization, root finding, numerical integration
  • How lm(), optim(), integrate() actually work

Computational statistics

  • Statistical methods that are made possible by computing
  • Simulation, Monte Carlo, bootstrap, jackknife, permutation tests, MCMC, density estimation, clustering, EM
  • Replace hard math with many cheap computations

Why can’t we just derive a formula? What happens when the sampling distribution of \(\hat\theta\) is unknown, the sample is small, or the model has no closed-form likelihood?

Why R?

  • Free, open source, runs everywhere (Windows, macOS, Linux)
  • Designed by statisticians for data analysis: vectors, data frames, formulas, models
  • 20,000+ packages on CRAN (and Bioconductor, GitHub)
  • Excellent graphics: base, lattice, ggplot2
  • Reproducible documents: R Markdown / Quarto (these slides!)
  • Interfaces to C/C++ (Rcpp), Python (reticulate), databases, the web

In this course: R first, with Python supplements when they illuminate a point. Everything you see on a slide is code you can run.

Writing Functions

sumdice <- function(n, sides = 6) {
  # simulate the sum of two dice n times
  k <- sample(1:sides, size = n, replace = TRUE) +
       sample(1:sides, size = n, replace = TRUE)
  return(k)
}
set.seed(2027)

A First Simulation: Law of Large Numbers

set.seed(4750)
n <- 5000
x <- rexp(n, rate = 2)           # E(X) = 1/2
running_mean <- cumsum(x) / seq_len(n)
plot(running_mean, type = "l", log = "x", lwd = 2, col = "#003366",
     xlab = "n", ylab = "running mean", main = "LLN: sample mean of Exp(2)")
abline(h = 0.5, col = "red", lty = 2, lwd = 2)

Python Supplement: the Same Ideas in numpy

import numpy as np
rng = np.random.default_rng(4750)
x = rng.exponential(scale=0.5, size=5000)     # Exp(rate = 2)
running_mean = np.cumsum(x) / np.arange(1, x.size + 1)
print(running_mean[[9, 99, 999, 4999]])

Summary

  • R is a vectorized language: think in vectors, matrices, and lists.
  • d/p/q/r functions give you every standard distribution.
  • Functions + sample() + loops/apply are enough to simulate almost anything.
  • Graphics: base R for quick looks, ggplot2 for layered, publication-quality plots.
  • Reproducibility: projects, relative paths, seeds, Quarto.
  • Install R, RStudio/Positron, and Quarto. Render this .qmd.
